# EP13 나레이션 TTS — 직접 생성용

claude.ai 쪽 API 스펜드 캡(이번 달 지출 한도)이 다 차서 자동 생성이 막혔습니다
(`ai.studio/spend`에서 한도 확인/조정 필요). 대신 Google AI Studio에서 직접 생성할 수 있게
텍스트를 전부 여기 정리해뒀습니다.

## 🇰🇷 한글 요약 — 어떻게 만들면 되는지

1. **https://aistudio.google.com** 접속 → TTS(음성 생성) 기능 사용 (모델: `gemini-3.1-flash-tts-preview`,
   안 보이면 `Gemini 2.5 Flash Preview TTS`처럼 비슷한 이름의 TTS 전용 모델 선택).
2. **목소리는 반드시 "Charon"**으로 선택 — 이 채널 전체(EP6~EP12)가 계속 이 목소리 하나만
   씁니다. 다른 목소리로 만들면 나레이터가 편마다 달라져서 안 됨.
3. 언어는 한국어(ko-KR)로 두되, Frame 9의 영어 문장 4개만 예외(아래 참고).
4. 아래 각 씬마다 있는 **"AI Studio에 넣을 프롬프트"** 코드 블록을 통째로 복사해서 그대로
   붙여넣으면 됩니다 — 맨 앞의 "Say only the narration..." 지시문까지 포함해서요. 이건 목소리
   톤(공감형, 자연스러운 속도)을 정하는 부분이라 지시문만 읽고 실제 나레이션은 안 읽습니다.
5. 생성된 오디오 파일을 **파일명 그대로**(`01.wav`, `02.wav`, ...) 아래 "저장 위치"에 저장.
   포맷은 가능하면 WAV, 24kHz/모노가 이상적이지만 다른 포맷이 나와도 실제 재생 길이만 정확하면
   문제없습니다(이 프로젝트는 음성 파일 실제 길이로 화면 길이를 계산하는 방식).
6. **Frame 9(리스닝 트레이닝)만 특별 처리** — 아래 "Frame 9 — 9조각으로 나눠서 생성" 절 참고.

## ⚠️ 생성 후 반드시 직접 들어볼 것 — 특히 이 씬들

아래 씬들은 한글 문장 중간에 **영어 알파벳 한 글자**(B, A, G, C, T, M, P)가 그대로 섞여
있어서, TTS가 이걸 이상하게 읽을 위험이 있습니다(SCRIPT.md에도 이미 적혀 있던 우려 —
EP12의 "Won't" 발음이 뭉개졌던 것과 같은 종류의 문제). **씬 1, 3, 5, 6, 7, 8, 10은 생성 후
꼭 들어보고, 알파벳 낱글자 부분이 이상하게 나오면 저에게 알려주세요** — 문장을 다르게
바꿔서 다시 시도하겠습니다.

## 씬별 프롬프트 (01~08, 10~12)

각 블록을 통째로 복사해서 AI Studio에 붙여넣으세요. (형식: 톤 지시문 + 빈 줄 + 실제 나레이션)

### 01 — 도입 (Stakes)

```
Say only the narration after the colon in an empathetic, natural pace tone.:

알파벳도 다 알고, 발음 규칙도 나름 공부하셨는데… 막상 처음 보는 단어 앞에서 딱 멈추신 적 있으시죠? 분명 A는 '애' 소리, B는 '브' 소리라고 배우셨는데, 단어 안에만 들어가면 완전 다르게 읽혀요. 그럴 때마다 "이건 또 왜 이렇게 읽지?" 하면서 하나씩 따로 외우다 지쳐서 포기하신 분들, 정말 많으실 거예요. 그거, 여러분이 이해력이 부족해서가 아닙니다. 지금까지 아무도 진짜 이유를 제대로 안 알려줬을 뿐이에요.
```

### 02 — 채널 인트로

```
Say only the narration after the colon in an empathetic, natural pace tone.:

안녕하세요, 「이해하면 쉬운영어」입니다. 오늘은 알파벳이 단어 안에서 왜 다르게 소리 나는지, 그 진짜 원리를 함께 봅니다.
```

### 03 — 질문 던지기 (Big Question)

```
Say only the narration after the colon in an empathetic, natural pace tone.:

그런데 궁금하지 않으세요? 왜 유독 영어는 같은 알파벳인데 단어마다 소리가 다 다를까요? 사실 이유는 간단해요. 한국어는 모음이 21개나 되는데, 영어 모음은 A, E, I, O, U 딱 5개뿐이거든요. 낼 수 있는 소리는 훨씬 많은데 글자는 훨씬 적으니까, 한 글자가 여러 소리를 돌아가면서 맡을 수밖에 없는 거예요. 그럼 결국 이 많은 경우의 수, 우리가 하나하나 다 외워야만 읽을 수 있는 걸까요?
```

### 04 — 반전 공개 (Head Fake)

```
Say only the narration after the colon in an empathetic, natural pace tone.:

결론부터 말씀드릴게요. 다 외우실 필요 없습니다. 원어민들이 저 많은 단어를 다 규칙으로 외워서 읽는 게 아니에요. 그냥 혀에 힘을 딱 빼고, 제일 편한 대로 소리를 내다 보니까 저절로 저렇게 되는 겁니다. 저도 예전엔 "왜 얘는 저렇게 읽고 쟤는 다르게 읽지" 하면서 하나하나 외우려다 지쳤었어요. 근데 알고 보니까 외우는 게 아니라, 힘을 빼는 원리 하나면 끝나는 거였습니다.
```

### 05 — 원리 설명 (메커니즘, 클라이맥스) ⚠️ 알파벳 낱글자 많음

```
Say only the narration after the colon in an empathetic, natural pace tone.:

원리는 이렇습니다. 혀에 힘을 딱 빼고 턱을 편하게 아래로 툭 떨어뜨리면, 자연스럽게 '애' 소리가 나요. 억지로 신경 써서 내는 소리가 아니라, 힘을 빼면 저절로 그렇게 되는 거예요. 예를 들어 BAG이라는 단어를 볼게요. B는 입술을 붙였다가 팡 떼면서 나는 소리, A는 방금 그 턱을 툭 떨어뜨리는 '애' 소리, G는 목 안쪽에서 편하게 나오는 소리예요. 이 세 개를 힘 빼고 자연스럽게 이어 붙이면 '백(BAG)'이 됩니다. 지금 제 입모양 한번 잘 보세요. 턱이 얼마나 편하게 내려가는지, 입술이 얼마나 힘 없이 움직이는지 — 이게 핵심입니다. 눈으로 직접 확인하시면 훨씬 빨리 감이 잡히실 거예요.
```

### 06 — 실제 단어로 확인 (패턴 확장) ⚠️ 알파벳 낱글자 많음

```
Say only the narration after the colon in an empathetic, natural pace tone.:

그럼 이게 진짜 다른 단어에도 통하는지 볼까요? CAT, 볼게요. C는 목 안쪽에서 바람 터지듯 나는 소리, A는 아까처럼 턱 내려가는 '애' 소리, T는 혀끝으로 톡 끊어주는 소리. 이어 붙이면 '캣(CAT)'이에요. MAP도 똑같아요. M은 입술 다물고 콧소리로 흠, A는 또 '애', P는 입술 팡 터지는 소리. 이어 붙이면 '맵(MAP)'. 어때요? BAG에서 썼던 그 '애' 소리, CAT에서도 MAP에서도 똑같이 통하죠? 이거 하나하나 다른 규칙으로 외우신 거 아니에요. 힘 빼는 원리 하나가 계속 통하는 겁니다.
```

### 07 — 반전 꿀팁 (예외) ⚠️ 알파벳 낱글자 있음

```
Say only the narration after the colon in an empathetic, natural pace tone.:

근데 눈치채신 분 있으실 거예요. 방금 CAT에서 C는 '크' 소리였잖아요. 근데 CITY나 CENTER 같은 단어에서는 C가 갑자기 '스' 소리로 바뀌어요. 이것도 그냥 외워야 하는 예외일까요? 아니요, 여기도 똑같이 힘 빼는 원리가 통합니다. C 바로 뒤에 E나 I처럼 입 앞쪽에서 나는 소리가 오면, 혀가 굳이 목 안쪽까지 가서 '크' 소리를 낼 필요가 없어져요. 이미 입 앞쪽에 있으니까, 그 자리에서 편하게 '스'로 끝내버리는 거죠. 그러니까 외우실 건 딱 하나예요. 뒤에 E, I, Y가 오면 혀가 귀찮아서 '스'로 바뀐다 — 이거 하나만 기억하시면 됩니다.
```

### 08 — 미니 퀴즈 ⚠️ 알파벳 낱글자 많음

```
Say only the narration after the colon in an empathetic, natural pace tone.:

직접 맞혀보세요. GAP이라는 단어, 어떻게 소리가 이어질까요? 잠깐 생각해 보시고… G, A, P를 힘 빼고 이어 붙이면 '갭'입니다. 하나 더요. PAT은요? … P, A, T 이어 붙이면 '팻'이죠. 이번엔 좀 다른 문제예요. CUP, C가 크일까요 스일까요? … 정답은 '크', 뒤에 U가 왔으니까요. 마지막으로 CELL은요? … 정답은 '스', 뒤에 E가 왔으니까요.
```

### 10 — 따라 말해보기 ⚠️ 한글 발음 표기(브/애/그 등) 확인

```
Say only the narration after the colon in an empathetic, natural pace tone.:

자, 이번엔 직접 해보세요. 아까처럼 소리 하나씩 힘 빼고 이어볼게요. 브, 애, 그 — 이어 붙이면, 백! 다시 한 번, 좀 더 빠르게. 백, 백. 이번엔 캣이에요. 크, 애, 트 — 이어 붙이면, 캣! 다시 한 번, 좀 더 빠르게. 캣, 캣. 이번엔 맵. 흠, 애, 프 — 이어 붙이면, 맵! 다시 한 번, 좀 더 빠르게. 맵, 맵. 마지막으로 예외도 같이 해볼까요? 셀이에요. 뒤에 E가 왔으니까 C는 스로 바뀌죠. 스, 에, 을 — 이어 붙이면, 셀! 다시 한 번, 좀 더 빠르게. 셀, 셀.
```

### 11 — 실생활 재확인 (페이오프)

```
Say only the narration after the colon in an empathetic, natural pace tone.:

이제 처음 보는 단어를 만나도 예전처럼 무작정 얼어붙진 않으실 거예요. 마트에서 'JAM'이라는 글자를 보셨다고 해볼까요. 바로 술술 읽히지 않아도 괜찮아요. 배운 대로 소리 하나씩 힘 빼고 천천히 이어보면, 즈, 애, 음 — 잼! 이렇게 시간이 걸리더라도 스스로 읽어낼 수 있게 되실 거예요. 이게 오늘 배운 원리의 진짜 힘입니다.
```

### 12 — 요약 + 마무리

```
Say only the narration after the colon in an empathetic, natural pace tone.:

오늘은 알파벳을 힘 빼고 편하게 이어 붙이면 소리가 저절로 만들어진다는 원리, 그리고 C처럼 예외로 보이는 것도 사실 같은 원리로 설명된다는 것까지 함께 봤습니다. 처음 보는 단어 앞에서 더 이상 얼어붙지 않으셨으면 좋겠어요. 다음에도 여러분이 자주 막막해하시는 부분, 또 풀어드릴게요. 저와 같이 하나씩 차근차근 익혀 나가시면, 어느새 훨씬 편하게 읽고 계실 거예요.
```

## 09 — 리스닝 트레이닝 (9조각으로 나눠서 생성 후 이어붙이기)

**왜 하나로 안 만드나**: 영어 예문 4개("There's a gap." 등)를 한국어 목소리 설정 그대로
보내면 어색하게 읽힐 수 있어서, **영어 문장 4개만 따로** 순수 영어 텍스트로 생성합니다
(EP11/EP12에서 이미 쓴 방식과 동일). 한국어 조각 5개 + 영어 조각 4개 = 총 9개를 순서대로
이어붙이면 하나의 09.wav가 됩니다.

아래 순서 그대로, **한국어 조각은 위와 같은 "Say only..." 지시문 포함**, **영어 조각은
지시문 없이 문장만** 그대로 붙여넣으세요(언어를 영어로 인식시키기 위함):

| 순서 | 종류 | 텍스트 | 붙인 뒤 무음 간격(초) |
|---|---|---|---|
| 1 | 한국어 | `Say only the narration after the colon in an empathetic, natural pace tone.:`<br>`이제 실제 속도로 들어보세요. 첫 번째.` | 0.3 |
| 2 | **영어** | `There's a gap.` | 0.5 |
| 3 | 한국어 | `Say only the narration after the colon in an empathetic, natural pace tone.:`<br>`두 번째.` | 0.25 |
| 4 | **영어** | `Pat the dog.` | 0.5 |
| 5 | 한국어 | `Say only the narration after the colon in an empathetic, natural pace tone.:`<br>`세 번째.` | 0.25 |
| 6 | **영어** | `Give me a cup.` | 0.5 |
| 7 | 한국어 | `Say only the narration after the colon in an empathetic, natural pace tone.:`<br>`네 번째.` | 0.25 |
| 8 | **영어** | `Check your cell phone.` | 0.6 |
| 9 | 한국어 | `Say only the narration after the colon in an empathetic, natural pace tone.:`<br>`오늘 배운 소리들, 실제 문장 속에서도 다 들리시죠?` | — |

9개를 각각 생성한 뒤, 위 표의 간격만큼 무음을 사이에 두고 순서대로 이어붙여서 하나의
`09.wav`로 만들어주세요. **오디오 편집 프로그램이 없으면 9개 파일을 각각
`assets/voice/09-1.wav` ~ `09-9.wav`로 저장만 해서 주셔도 됩니다 — 이어붙이는 건 제가
ffmpeg로 처리하겠습니다.**

## 참고 — 시도한 자동화

`scripts/gen-tts-gemini.mjs`(이 프로젝트 폴더 안)에 위와 똑같은 내용을 넣어 자동 생성을
시도했으나, claude.ai 연동 API 키의 이번 달 스펜드 캡 초과로 막혔다(2026-09-05,
`ai.studio/spend`에서 한도 조정 가능). 한도를 올리면 이 스크립트로 한 번에 생성 가능 —
`node scripts/gen-tts-gemini.mjs --only=05`처럼 씬 하나만 먼저 테스트할 수도 있음.
