# 채널 프로필 사진 생성 프롬프트

소리/발음이라는 채널 핵심 테마(모든 시안 카피에 "소리", "귀 뚫림" 반복)를 사운드웨이브로
추상화. 원형 크롭·작은 크기에서도 읽히도록 텍스트 없이 단순 도형+브랜드 컬러로만 구성.

```
A minimal, bold logo mark for a Korean English-pronunciation education YouTube channel,
designed as a square profile picture that will be cropped into a small circle.

Background: solid dark navy (#0A1526), no gradient, no glow, no texture.

Mark: a simple, abstract sound wave / audio equalizer motif — 5 to 7 vertical bars of
varying height, evenly spaced, centered in the frame, filling about 60% of the canvas
width. Render the bars in the channel's three brand colors used together in one clean
gradient-free arrangement: bright yellow (#F5C518), sky blue (#5B9BD5), and red (#E84545)
— distribute the three colors clearly across the bars (do not blend them into each other).

Style: flat vector graphic design, crisp hard edges, no photorealism, no 3D, no drop
shadows, no gradients, no textures, no realistic materials.

Composition: perfectly centered, generous even padding on all four sides so the mark
reads clearly even when cropped into a small circle.

Do not render any text, letters, numbers, logos, watermarks, or human figures anywhere
in the image — the mark itself is the only visual element.
```

## 참고
- 정사각형 캔버스(예: 1024x1024)로 생성할 것 — 유튜브가 자동으로 원형 크롭한다.
- 텍스트를 완전히 배제한 이유: 프로필 사진은 실제 노출 크기가 매우 작아(20~40px대) 글자가
  거의 항상 뭉개진다 — 오늘 썸네일 작업에서 확인한 "작은 크기에서 안 읽히는 문제"와 같은 이유.
- 막대 개수·색 배분 등은 실제 생성 결과를 보고 조정 가능 — 이건 초안 1개다.
