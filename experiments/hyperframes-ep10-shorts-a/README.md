# HyperFrames 비교 실험 — EP10 쇼츠 A

상태: 준비 완료, 시제품 제작 대기

## 목적

기존 Remotion을 교체하기 전에 EP10 쇼츠 A의 대표 10~15초 구간을 HyperFrames로 제작해 실제 품질과 작업 효율을 비교한다.

## 보호 원칙

- 기존 Remotion 코드와 완성 영상은 수정하지 않는다.
- 전체 EP10 쇼츠를 먼저 이전하지 않는다.
- 비교 결과가 확인되기 전에는 HyperFrames를 채널 표준으로 채택하지 않는다.
- 디자인 규칙과 렌더링 엔진 채택 여부를 별도로 판단한다.

## 비교할 대표 장면

1. 질문 또는 오독 제시
2. 영어 철자 강조
3. 한글 발음 강조
4. 정답 공개와 짧은 전환

## 합격 기준

| 항목 | 확인 내용 |
|---|---|
| 디자인 | 현재 Remotion 결과보다 명확하고 세련됐는가 |
| 동기화 | TTS 발화와 철자·한글 색상 전환이 정확한가 |
| 수정 속도 | 위치·크기·모션 수정이 더 빠른가 |
| 한글 품질 | 폰트, 외곽선, 줄바꿈, 글자 잘림이 안정적인가 |
| 렌더 안정성 | 같은 입력에서 같은 프레임과 오디오가 나오는가 |
| 재사용성 | A·B·C에 공통 기반으로 확장할 수 있는가 |

## 판정

- 명확한 우위: 시즌2부터 HyperFrames 중심 전환 검토
- 모션만 우위: HyperFrames를 짧은 모션 소스 제작기로 사용하고 Remotion에서 조립
- 우위 불명확: Remotion 유지, `frame.md`식 디자인 규칙만 채택
