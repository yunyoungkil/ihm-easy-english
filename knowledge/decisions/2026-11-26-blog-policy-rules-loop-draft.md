## 0. 한 줄 요약

블로그 규칙은 유튜브 규칙과 **따로 두고**, 슬로건과 **공통 안전선**(같은 애드센스 계정, 지어낸 경험 금지, 진짜 숫자만, AI 티 검사, 저작권)만 함께 쓴다. 자료집에서 새로 쓸 것은 안전선 3개, 글쓰기 기본값 4개, 시험 거리 5개이고, 가장 큰 빈칸은 **결과를 재서 다음 주제에 되먹이는 장치가 아직 없다**는 것이다.

## 1. 유튜브와 무엇을 함께 쓰고 무엇을 나누나

| 구분 | 내용 | 어디에 둠 |

**나누는 이유 (확인한 것)**
1. 무인 글쓰기는 `--restricted`(제한 모드)로 돌아서 `CLAUDE.md`·`AGENTS.md`를 **아예 읽지 않는다**. 11/26 같은 질문으로 세 번 시험했다: 초안 폴더에서 제한 모드 → "지침 없음", 저장소 맨 위에서 제한 모드 → "지침 없음", 제한 모드 없이 → 슬로건과 "3060"을 읽어 냄. 그래서 블로그 규칙은 `AGENTS.md`에 넣어도 글쓰기에 닿지 않는다. 글쓰기 지침에 있어야 작동한다.
2. 독자가 다르다. 유튜브는 3060 국내 영어 학습자, 쿠팡 블로그는 나이를 정하지 않은 검색 방문자다(설계 6-2).
3. 지켜야 할 바깥 규칙이 다르다. 블로그는 공정위 추천·보증 심사지침, 쿠팡 파트너스 이용 가이드, 구글 검색 스팸 정책, 네이버 서치어드바이저를 따른다.
4. `AGENTS.md`는 75KB 한도이고 모든 대화가 읽는다. 블로그 규칙을 넣으면 영상 작업 때마다 비용이 든다.

**완전히 떼면 안 되는 이유 (확인한 것)**: 애드센스 정책은 "검색 스팸 정책을 어긴 화면에는 광고를 달 수 없다"고 한다(애드센스 10502938). 블로그가 애드센스 경고를 받으면 같은 계정인 유튜브 수익까지 걸린다. 그래서 공통 안전선은 두 쪽에 다 있어야 한다.

**슬로건의 블로그 풀이 (초안)**: 슬로건은 그대로 함께 쓴다. 다만 무인 글쓰기는 슬로건을 못 읽으니 글쓰기 지침에 아래 풀이를 넣어야 실제로 함께 쓰는 것이 된다.
- "여러 명작의 원리를 흡수" → 검색 상위 글들이 **무엇을 놓쳤는지** 보고 그것을 더한다. 상위 글을 베끼는 것이 아니다(구글 "얇은 제휴", 애드센스 "덧붙인 해설 없이 복사한 화면" 금지와 부딪힌다).
- "AI 템플릿·평균값을 벗어남" → 글마다 소제목 수·순서·문단 틀을 다르게(지금 지침 2절 그대로).
- "매 편 기존 영상을 넘어선다" → 매 글이 같은 주제의 이전 글과 상위 글보다 독자에게 하나 더 준다.
- "결과로 배운다" → 7절 결과 루프.

## 4. 기본값 (근거를 적으면 바꿀 수 있음)

이미 있는 것: 주 3편(월·수·금 02:00), 링크 글 2 : 정보 글 1, 글자 링크(배너 없음), 대표 그림 자체 제작 1장, 운영자 표기는 블로그 이름, AI 사용은 소개 페이지에 공개(구글 "도움이 되는 콘텐츠" 문서의 권고와 맞음, 11/26 확인), 단계마다 출처 원문 인용.

**새로 넣자는 것 (가설, 글의 틀이 아니라 독자가 얻는 것 기준이라 탈템플릿과 부딪히지 않음)**
1. 검색해서 온 사람이 첫 화면에서 답의 방향(가장 흔한 원인, 확인 순서)을 본다. 근거: AI 요약이 뜨면 1위 글 클릭률이 낮아진다는 실측(Pew 8% 대 15%, 아레프스 -58%, 둘 다 상관관계). 요약되기 어려운 구체적 순서·조건이 남는다는 해석은 가설.
2. 안 맞는 경우·한계·사지 말아야 할 조건을 함께 적는다(특히 `before-buy`). 근거: 자료집의 양면 설명 연구. **논문 원문은 확인하지 않았다**(가설).
3. 상위 글이 주지 않는 것을 하나 더한다(공식 문서 대조, 규격 숫자, 안전·백업 주의 등). 근거: 구글 "얇은 제휴" 정의가 "가치를 더하지 않은 것"을 문제 삼음(확인).
4. 규격 숫자는 출처와 함께 쓴다. 근거: GEO 논문(통계 추가 약 +31%, 출처 인용 약 +28%). 단 이것은 AI 답변 안의 노출이지 구글 순위가 아니다(확인).

## 5. 시험 거리 (정하지 않고 결과로 정함)

시작 조건: 글 12편 이상, 색인 확인, 첫 4주가 지난 뒤(자료집 6-1). 한 번에 하나씩 바꾼다.
1. 글자 링크 대 깜빡이지 않는 버튼(쿠팡 금지 목록 안에서) — 쿠팡 클릭률

## 6. 한 바퀴 순서

**쿠팡 블로그**
1. 주제 고르기(대화 안, 대기열 6개 미만일 때): 옛 서치 콘솔 검색어 → 자동완성·지식iN으로 수요 확인 → 특정 모델 하나보다 **반복되는 오류·호환 규격·소모품** 쪽을 고른다(모델은 금방 단종, 자료집 2-1, 가설) → **새로**: 같은 큰 주제의 글끼리 묶어 서로 링크한다(지금은 글 사이 링크가 없다).
2. 글쓰기(무인, 월·수·금 02:00, 집 PC): 글쓰기 지침만 읽는다.
3. 자동 점검 → 게시 → 바깥에서 주소를 열어 확인.
4. 검색 등록: 사이트맵·RSS로 자동. 네이버는 서브도메인마다 등록하고 사이트맵·RSS(본문 전체)를 내면 되며 반영까지 최대 1주(서치어드바이저 가이드, 확인). `tech.d40m.com` RSS는 본문 끝까지 담겨 있다(11/26 확인). **새 글마다 손으로 수집 요청은 하지 않는다**(공식 가이드에 없고 자동화 원칙과 맞지 않음, 자료집 1-3 ① 수정).
5. 주 1회 경고 화면 점검(대화 안, 프로젝트 크롬): 서치 콘솔·애드센스·쿠팡.
6. 4주마다 결과(7절).

**영어 블로그**: 롱폼 예약 마무리 때 복습 글을 영상 공개 시각으로 예약 게시(설계 6-3). 영상 퍼오기 + 직접 쓴 해설·단어·퀴즈, 광고는 버튼·영상에서 떨어진 자리, 글 적은 화면은 광고 끔.

- 판정: 글 수가 적을 때는 가설로만 적는다. 글 종류·주제 묶음 단위로 비교한다.
- 기록: `data/blog/tech-posts.json`에 글마다 성과 칸, 블로그용 시험 표(유튜브 `style-experiments.md`와 같은 역할)를 새로 둔다.
- 되먹임: 노출·클릭이 붙은 주제 묶음을 대기열 앞으로, 4주 동안 노출 0인 글은 제목·첫 화면 고치기 후보(올린 글을 고쳐도 되는지는 9절).
- 만들어야 할 것: 수집 프로그램(서치 콘솔·쿠팡), 성과 칸, 시험 표, 브리핑 한 줄. 첫 4주가 끝나는 12/24(4주 점검일) 전에 있으면 된다.

## 8. 점검 프로그램에 더할 것 (원문 확인 + 실측)

**출처 인용문이 실제 페이지에 있는지 대조한다.** 지금 점검은 출처 주소가 열리는지(200)와 인용문이 비어 있지 않은지만 본다. 구글은 "AI로 만든 글은 사람이 사실 확인하라"고 한다(using-gen-ai-content 문서, 확인). 사용자는 품질 판단을 맡지 않으므로, 사람 대신 프로그램이 인용문을 원문과 글자 단위로 대조하는 것이 가장 가까운 방법이다. 11/26 첫 글로 시험: 13개 단계 중 그대로 비교하면 10개, **따옴표 모양(“ ” → ")을 맞추면 13개 모두** 실제 페이지에 있었다. 자바스크립트로 그려지는 페이지는 못 읽을 수 있으니 그런 출처는 "확인 못 함"으로 따로 센다.

## 9. 사용자가 정할 것

1. **사람 확인**: 구글은 사람의 사실 확인을 권하고, 우리는 "자동 점검을 통과하면 바로 게시"로 정했다(11/24). 권고: 결정은 그대로 두고 8절 대조 검사를 더한다. 사용자에게 글 검토를 맡기지 않는다.
2. **올린 글 고치기**: 결과 루프에서 노출 없는 글의 제목·첫 화면을 고쳐도 되는가. 유튜브는 "이미 만든 영상은 고치지 않는다"지만 블로그 글은 고치는 일이 흔하다.
3. **`AGENTS.md` 한 줄**: "블로그 규칙의 원본은 블로그 문서, 공통 안전선만 여기"를 넣을지(규칙 문서 변경이라 승인).

## 10. 자료집에서 고치거나 뺀 것

1. "쿠팡 오픈 API 약관 제5조·제6조, 약관 제12조": 원문으로 확인 못 함. 찾은 비슷한 조항은 판매자용 API 연동 협약서 제3조③이라 대상이 다르다.
2. "대법원 2017도19025 → 공식 유튜브 퍼오기 합법": 이 판결은 **불법 게시물에 링크한 행위의 방조** 사건이라 근거가 안 된다. 퍼오기 근거는 유튜브 약관 쪽(일부 확인).
3. "C-Rank·D.I.A.가 외부 사이트에도 적용": 공식 문장은 "내외부 UGC 문서"까지만 있고 외부 블로그 적용은 확인 못 함. D.I.A.+는 공식 근거 없음.
4. 네이버 쇼핑 커넥트 외부 블로그 사용·수수료율, 카카오 9%·토스 5%: 공식 근거 못 찾음 또는 확인 안 함(지금 필요 없음).
5. 아레프스 86.5%·0.011(2025-07, 60만 페이지)과 54.7%(2026-07, 다른 연구, "1~3위"라는 말 없음)는 서로 다른 연구다.
6. 시어 61%는 클릭 수가 아니라 클릭률이고, 인용된 사이트의 +35%는 인과가 아니다(시어 본문이 직접 밝힘).
7. GEO +40%는 AI 답변 안의 노출이지 구글 순위가 아니다.
8. 애드센스 문구를 따옴표로 쓴 부분은 원문과 다르다(원문은 3절 5번 출처).
9. "새 글마다 네이버 수집 요청"은 공식 가이드에 없다.

## 11. 확인하지 못한 것

- 쿠팡 파트너스 이용약관·운영정책·오픈 API 약관 본문(상품 사진 허용 범위): 보조 AI의 접속이 막혔다. 프로젝트 크롬은 파트너스에 로그인돼 있으니 사진을 쓰는 시험(5절 2·3번) 전에 직접 연다.
- 양면 설명·설득 지식 모델 논문 원문.
- 유튜브 상업 사이트 퍼오기 세부 약관(YouTube API 서비스 약관).
