# BRIEF — ep22-ed-ending (단편 EP22 — 영어 과거형 -ED 끝소리 규칙, t/d/id)

## Intent

대시보드 아이디어 보드(`idea-board.mjs`)가 아니라 **`.claude/skills/episode-planning` 신규
워크플로우**(2026-10-03 신설, `CLAUDE.md` 참고)로 선정. 이 워크플로우는 기존 대시보드가
캐시해 둔 `data/youtube/*.json` 스냅샷을 그대로 인용하지 않고, 매 단계 라이브로 다시 조회한
데이터만 근거로 쓴다. 전체 과정:

### Phase 1 — 라이브 데이터 분석 (2026-10-03, `/api/sync` 강제 새로고침 직후 값)

- **채널 현실**: 조회 범위 2026-07-04~10-01 기준, 쇼츠 25,530회(98.0%) vs 롱폼 511회(2.0%).
  검색 유입은 647회(2.5%)로 사실상 없음 — 상위 검색어 1위 "영단어"(203회)를 빼면 나머지는
  1~7회 수준.
- **이미 다룬 소재 전수 스캔**(`videos/*/BRIEF.md`): 매직 E, C/K 경음, G 경음/연음, 슈와,
  연결어 축약(gonna), -TION/-SION/-TURE/-CIAL, want/won't, bossy R, 묵음 자음(KN/MB/WR),
  -ATE 강세축약, World류 R+L 인접, Flap T — **-ed/-s 같은 표준 굴절 접미사 발음 규칙은
  한 번도 다룬 적 없음을 확인**.
- **웹 검색으로 사실관계 1차 확인**: -ed 과거형 발음의 t/d/id 삼분은 앞 소리의 유성/무성
  여부로 갈리는 표준 음운 현상(동화, assimilation)이라는 것을 교차 확인
  (perfect-english-grammar.com, englishpost.org 등 복수 출처).

### Phase 2 — 소재 후보 10개 중 ① 선정

후보 10개(①-ed 과거형, ②-s/es 복수형, ③TH, ④V/B, ⑤명사·동사 강세이동, ⑥묵음 H, ⑦끝소리
Y, ⑧NG 콧소리, ⑨CH/SH/J, ⑩문장 강세 리듬) 중 **① -ED 과거형 끝소리(t/d/id)**를 사용자가
우선순위 1번으로 선택. ②(-s/es 복수형)는 **같은 유무성 동화 원리를 공유하는 자매 소재**라
EP23 이상에서 "2부작"으로 이어갈 후보로 남겨둠(`idea-board-history.json`류 파일 대신 이
BRIEF.md 자체가 다음 기획 때 참고할 기록임).

### Phase 3 — 포맷 결정

**롱폼 단독**으로 확정(쇼츠 연계는 보류). 쇼츠 연계 아이디어("wanted/walked/played 끝소리
퀴즈 → 롱폼 유도")는 떠올랐으나 이번엔 채택하지 않음 — 추후 재검토 가능.

## 확정된 제목·썸네일

Phase 4(2026-10-03) — 검색의도·호기심갭·구체성 체크리스트로 직접 판단(AI 가상 CTR 점수
미사용), 3개 시안 중 A 선택:

| 시안 | 제목 | 썸네일 헤드라인 | 근거 |
|---|---|---|---|
| **A (채택)** | Wanted, Walked, Played — 끝소리 세 개가 다 다릅니다, 영어 과거형 -ED 발음 규칙 | "-ED, 다 '드'로 읽으셨죠?" | 검색 키워드("영어 과거형 -ed 발음")가 제목 앞부분에 그대로 노출 + 구체적 단어 3개 나열 |
| B | 원어민은 -ED를 절대 '드'로 안 읽습니다, 당신만 몰랐던 진짜 발음 규칙 | "당신만 몰랐던 -ED" | 호기심 갭은 강하나 검색 키워드가 뒤로 밀려 검색 유입 개선 목적엔 A보다 약함 |
| C | 영어 선생님도 안 알려준 과거형 끝소리 비밀 | "-ED, 3가지 소리" | 클로즈업용 막연한 호기심형, 구체성 가장 약함 — B/C는 보존만 하고 미채택 |

Phase 1에서 확인한 "검색 유입 2.5%, 사실상 0" 문제를 가장 직접적으로 겨냥한다는 점에서 A를
선택. B/C는 버리지 않고 보존(`title-variants.txt` 작성 시 유튜브 Studio A/B 테스트용으로
활용 가능).

이미지 프롬프트는 `prompts/thumbnail-prompts.md`에 저장됨(메인 1개+클로즈업 1개, 현재
채널 표준 스타일인 무지 크림 배경+앵커 단어+골드 알약 기준).
