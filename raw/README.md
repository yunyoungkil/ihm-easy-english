# 원본 자료

이 폴더는 위키가 참고하는 원본 자료를 변경 없이 보관한다.

## 원칙

- 원본은 읽기 전용으로 취급하며 요약·교정 내용을 직접 덮어쓰지 않는다.
- 기사, 대화 내보내기, 참고 문서, 이미지와 분석 자료를 출처별 하위 폴더에 넣는다.
- YouTube API 원본은 기존 `data/youtube/`가 담당하므로 이곳에 복제하지 않는다.
- 원본에서 얻은 판단과 연결 관계만 `knowledge/`에 기록한다.

## 권장 구조

```text
raw/
├─ articles/
├─ conversations/
├─ references/
└─ assets/
```
