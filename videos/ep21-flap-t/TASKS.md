### 13. 1차 생성 시도 — 사용자가 "탁 끊기는 문제 해결 안됨"으로 재지적
"만들어봐" 승인 후 첫 실행에서 두 가지 문제 발견:

   수정(`/history/{id}`를 5초 간격으로 폴링). 첫 실제 추론은 모델 워밍업으로 60~100초대
   소요, 이후엔 빨라짐(GPU 사용률 38%로 확인 — 멈춘 게 아니라 느린 것뿐이었음).
2. **사용자가 "온점→말줄임표" 트릭만으론 부족하다고 지적, 실제 해결책 제시**: "나레이션이

### 14. "끝" 희생 문장(sacrificial tail) 기법 구현·검증
- `appendSacrificialTail()`: 나레이션 텍스트 끝에 ` 끝.`을 붙여서 전송 — Voicebox가
  진짜 내용 이후에 반드시 한 문장을 더 말하게 만듦.
- `findSacrificialCutPoint()`: 생성된 오디오를 20ms 단위 RMS로 스캔, 끝에서부터
  역순으로 "무음 → '끝' 발화 구간 → 무음"을 찾아 그 경계(진짜 내용이 끝나는 지점)의
  바이트 오프셋을 반환. 경계를 못 찾으면 `null`을 반환해 **추측으로 자르지 않고**
  원본을 그대로 보존 + 경고 로그.
- 자른 지점에는 클릭 방지용 40ms 짧은 페이드아웃만 추가(원래 버그 자체의 수정이 아니라
  자르기 자체가 만드는 이음매 잡음 방지용).
- **whisper로 실제 검증**: `.whisper/main.exe` + `ggml-small.bin`(이미 이 저장소에
  설치돼 있던 모델)로 결과물을 직접 전사해서 (a) "끝"이 안 남아있는지, (b) 진짜 내용이
  안 잘렸는지 확인. 02번(14.18s)·06번(가장 긴 101.40s)·07번(예외 처리 후) 전부 whisper로
  대조 확인 — 셋 다 실제 SCRIPT.md 원고와 정확히 일치, "끝" 유출 없음.
