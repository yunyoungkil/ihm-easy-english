## 프레임별 디자인 및 UI 가이드라인

### 1. 색상 체계 (사운드 타입별 컬러 매핑)
- **[s] 무성음 (성대 떨림 0%)**: 코랄 레드 (`#DC2626` / 배지 `#FEE2E2`, 텍스트 `#991B1B`)
- **[z] 유성음 (성대 떨림 100%)**: 스카이 블루 (`#2563EB` / 배지 `#DBEAFE`, 텍스트 `#1E40AF`)
- **[ɪz] 쿠션 모음 (+1음절)**: 에메랄드 그린 (`#059669` / 배지 `#D1FAE5`, 텍스트 `#065F46`)
- **[ɪz] 특수 예외**: 앰버 골드 (`#D97706` / 배지 `#FEF3C7`, 텍스트 `#92400E`)

### 2. 컴포지션 공통 UI 표준
- **어간 뉴트럴 + 접미사(-s, -es) 분리 표기**:
  - 예: `<span class="word-stem">cat</span><span class="word-s ed-s">s</span>`
  - 예: `<span class="word-stem">dog</span><span class="word-s ed-z">s</span>`
  - 예: `<span class="word-stem">bu · </span><span class="word-s ed-iz">ses</span>`
- **UI 텍스트 자동 줄바꿈 방지 (`white-space: nowrap`) 강제**:
  - 알약, 팁 박스, 뱃지, 영문 단어 등 모든 주요 UI에 줄바꿈 방지 적용.
- **불필요한 메타 라벨 제거**:
  - 점 6개 인디케이터만 중앙에 노출하고 설명 라벨 삭제.
