# EP10 CONFUSION Pilot

## Frame 1 — 질문에서 원리까지
- **Status:** animated
- **Duration:** 12s
- **Transition:** cut
- **Type:** hook / concept reveal
- **Persuasion:** question-answer pairing, progressive disclosure
- **Beat:** curiosity → correction → aha → hold
- **Voiceover:** “컨퓨전은요? 전입니다. 모음 뒤라서요.”
- **Blueprint:** kinetic type beats, adapted for a beginner pronunciation lesson
- **Focal:** CONFUSION → 컨퓨전 → U + SI → 전

### Timing
- 0.0–3.2s: 질문과 선택지
- 3.2–4.7s: “컨퓨전은요?”
- 4.7–5.9s: “전입니다.” 정답 공개
- 5.9–7.9s: “모음 뒤라서요.” 원리 시각화
- 7.9–12.0s: 결과를 읽는 정지 구간

### Design rules
- `frame.md`의 Rockabilly Day 인쇄 포스터 스타일을 그대로 따른다.
- 크림 종이, 잉크 검정, 빈티지 빨강, 민트의 4색과 미스레지스트레이션을 유지한다.
- 모션은 하드컷, 1프레임 판 교체 플래시, 1프레임 잉크 정합 흔들림만 사용한다.
- 안전영역은 상단과 하단만 확보한다.
- 확정 템플릿이 아닌 비교용 파일럿이다.
