# 레퍼런스 영상 비주얼 분석 기록

경쟁/레퍼런스 영상에서 화면 구성·모션·전환 기법을 뽑아 우리 채널(HyperFrames)에 접목할 때,
분석 결과를 여기 누적한다 — 매번 새로 보지 않고 다음에 다시 찾아볼 수 있게.

**분석 방법(2026-09-16부터)**: `/watch` 스킬(`bradautomates/claude-video`, 로컬 설치 완료 —
`~/.claude/skills/watch`)로 직접 영상을 다운로드해 장면 전환 기준 프레임을 뽑고 자막을 읽어서
분석한다. 예전처럼 사용자가 제미나이에 따로 분석을 부탁할 필요 없음. 대본 전문을 그대로
옮기지 않고 화면 디자인·구조 요약 위주로 기록한다(저작권 있는 텍스트 대량 인용 금지).

⚠️ Windows 환경에서 `/watch` 실행 시 참고: 이 컴퓨터에서 스킬 자체의 버그 2개를 고쳐야 했다
(둘 다 `~/.agents/skills/watch/scripts/`의 원본 소스를 직접 수정, 심볼릭 링크라 Claude Code
쪽에도 자동 반영됨) — ① `setup.py`의 print문에 있는 em-dash(—)가 Windows 콘솔 기본 코드페이지
(cp949)에서 `UnicodeEncodeError`를 내서, 실행 전 `PYTHONUTF8=1`/`PYTHONIOENCODING=utf-8`을
환경변수로 걸어야 함. ② `frames.py`가 쓰는 `-vsync vfr` 옵션이 최신 ffmpeg(9.0)에서 제거돼
`-fps_mode vfr`로 교체했음(값은 동일, 옵션명만 바뀜). 재설치/업데이트하면 이 패치가 사라질 수
있으니, 같은 에러가 다시 나오면 이 두 가지부터 확인할 것.

## 2026-09-16 — "유튜브 첫 영상 만들기" 동기부여 영상 (https://youtu.be/ZWKxukGWF5U)

약 20분, 토크형(talking-head) + B롤 컷어웨이. 신규 유튜버에게 "완벽하지 않아도 일단
시작하라"는 동기부여 메시지를 전달하는 영상으로, 발음 교육 콘텐츠와는 장르가 다르지만
**화면 구성 기법**은 참고할 만하다.

**뽑아낸 기법**:

1. **키워드 펀치 자막**: 말하다가 강조하는 단어 하나("SO", "EVERY" 등)만 화면 하단에
   두껍고 큰 흰색 산세리프로 순간적으로 박아 넣는다. 자막 전체 문장이 아니라 **딱 한 단어만,
   화면을 가득 채울 크기로** — 우리 채널의 inline-highlight(문장 안 형광펜)와는 발상이 다른,
   훨씬 더 공격적인 강조 방식.
2. **단계별 컷어웨이 B롤**: 말하는 내용의 각 단계(기획→대본→촬영→편집)에 맞춰, 그 단계를
   실제로 보여주는 화면을 끼워 넣는다 — 다이어리 읽는 장면(기획), 모니터 앞에서 텍스트
   에디터 보는 장면(대본), 폰을 삼각대에 놓고 카메라 앱 켠 장면(촬영), 어두운 테마의 영상
   편집 타임라인 화면(편집). **"말하는 개념 = 화면에 나오는 실제 행동"으로 1:1 매칭**시키는
   구조라 추상적인 설명이 훨씬 구체적으로 느껴진다.
3. **따뜻/차가운 조명 대비 세팅**: 좌측 우드 셀프는 앰버 전구(따뜻함), 배경 커튼은
   블루/퍼플 LED 백라이트(차가움) — 한 프레임 안에 두 색 온도를 동시에 써서 공간에 입체감을
   준다.
4. **엔드카드**: 어두운 배경에 살짝 기울어진(skew) 흰색/빨간색 텍스트로 "SUBSCRIBE",
   "WATCH NEXT", "THANK YOU FOR WATCHING"를 겹쳐 배치.

**적용 아이디어 (미착수, 다음에 논의)**:
- 2번(단계별 컷어웨이)은 우리 발음 규칙 설명 프레임에도 빌려올 수 있다 — 예를 들어
  "혀의 위치가 바뀐다"를 말로만 설명하지 않고, 그 순간 실제 입 모양 일러스트가 그 동작을
  하는 것처럼 타이밍을 맞추는 식. 현재 `illustration-slot` 컴포넌트가 이미 이 역할에
  가깝지만, "나레이션의 각 단계 ↔ 화면 전환"을 더 촘촘하게 맞추는 여지가 있음.
- 1번(키워드 펀치 자막)은 우리 채널의 "정답 누설 방지 원칙"(TTS가 답을 말하면 안 됨)과
  충돌할 수 있어 신중히 검토 필요 — 화면에 큰 단어가 뜨는 순간과 정답 공개 타이밍이 겹치면
  스포일러가 될 수 있음.
