## 2. PHASE 7·9 — 시각 선행(Info Doc → Visual Outline) & 3중 하이브리드 분업

화면의 AI 템플릿 냄새와 AI 평균값을 없애는 출발점은 **① 글을 먼저 쭉 쓰고 화면을 끼워 맞추지 않고, 시각 자료(Info Doc)와 거친 장면 흐름(Visual Outline)만으로 이야기가 통하게 먼저 짠 뒤 대사 군살을 걷어내는 것(Show, Don't Tell)**, 그리고 **② 화려한 모션·그래픽을 먼저 고르지 않고 이번 편이 선택한 핵심 심리·스토리 원리(및 계단식 오픈 루프 — 초반 답을 다 닫아 이탈하는 Payoff Void 방지)를 시청자 머리에 가장 선명하게 전달·증명하는 수단으로 각 도구의 강점을 나누어 쓰는 것**이다.

| 장면 성격 | 주력 도구 | 이유 (2026-11-21~22 유튜브 94편 조사·실측) |
|---|---|---|
| **실사 상황, 인물 표정·대사, 실제 사물·공간의 유기적 동작** | **`Omni 1.2 Flash`** (`npm run video`) | 코드로 만들 수 없는 진짜 질감·자연스러운 호흡·환경음·한국어 립싱크까지 생성 |
| **종이 콜라주, 찢어진 질감, 실물 컷아웃 레이어 모션** (입 구조, 단어 분해 등) | **`Nano Banana 2.1`** (`npm run image`) + **`HyperFrames`** 레이어 애니메이션 | 이미지 AI의 실물 질감 + 코드의 정밀한 레이어 움직임(그림자 추적·12fps 스톱모션·만화경 등) 결합 |
| **한글 타이포그래피, 발음 강조, UI 오버레이, 발화 싱크, 컷 전환** | **`HyperFrames` + GSAP** | 영상 AI는 한글 자소가 뭉개지고 세부 수정이 불가. 선명한 한글·정확한 타이밍은 코드가 전담 |

### 제작 전 시각 레퍼런스 & 최신 영상미 탐색 (`kr.pinterest.com` + 웹/유튜브 + `visual-library`)
- **Pinterest + 최신 트렌드 사전 리서치 (2026-11-22 사용자 지시)**: 영상을 설계하기 전에 **`https://kr.pinterest.com/`에서 주제·연출 키워드로 참고 이미지·영상·타이포·색감 무드보드를 찾고**, 웹·유튜브 검색으로 **요즘 시청자가 반응하는 최신 영상미·모션 트렌드**를 확인한다(우리 지식과 과거 데이터에만 갇히지 않는다).

## 3. PHASE 10 — 무료 생성 도구 제작 도구 상자 & 후반 휴먼터치

상세 CLI 플래그·프롬프트 문법은 **`knowledge/google-ai-studio-prompting.md`** 를 참고한다.

### 1. 이미지·영상 생성 도구 상자 (`npm run image` · `npm run video` · `npm run video:flow` · `npm run video:gemini`)
상황에 맞는 기법만 골라 쓴다(단순 2컷 영상에 불필요한 시트/그리드를 억지로 만들지 않는다).
- **영상 3단 계층 폴백 & Google Flow 활용 (2026-11-23 실측 구축)**:
  - **1순위 AI Studio (`npm run video`, Omni 1.2 Flash)**: 워터마크 0px·1080p·크롭 손실 0%. 얼굴 클로즈업·입 모양(한국어 대사)·디테일 핵심 히어로 컷에 우선 배정(하루 약 6회).
  - **2순위 Google Flow (`npm run video:flow`, PRO 월 1,000+일 50크레딧)**: AI Studio 한도 소진 시·다중 테이크 시험 시 자동 사용(사전 15% 여백 프롬프트 + 하단/우측 12.5% 중앙정렬 크롭 → 1080p + 4모서리 검수 자동 수행). 또한 **연속 컷 캐릭터 일관성(`캐릭터`/`소재`), 첫·끝 프레임 전환(`프레임`), 생성 클립 대화형 부분 수정(`Omni 1.2 Flash`)·`프레임 저장`, 0크레딧 `Nano Banana 2.1` 이미지, 커스텀 `도구 만들기`**가 필요할 때 Flow 작업 공간을 적극 활용한다.
  - **3순위 Gemini 앱 (`npm run video:gemini`, Gemini Omni 9:16·16:9 10초)**: AI Studio·Flow 모두 소진 시 보조 사용(동일 사전 여백+자동 크롭+4모서리 검수). 이미지 비상 폴백은 `npm run image:gemini`.
- **시각 스토리보드 시트 선설계 & 멀티컷 한 번에 뽑기 (2026-11-22 사용자 지시)**:
  - 본격 영상 생성 전, **상단 메타(길이·스타일·오디오 무드) + 컷별 시간 구간(`0-2.5s` 등)·시각 컷·`VISUAL / ACTION / DIALOGUE`·효과 포인트(`POP!`, `ZOOM!` 등)**가 한눈에 보이는 시각 스토리보드 구조로 전체 흐름·흥미·도파민 리듬을 먼저 설계한다.
  - 여러 컷이 이어지는 영상은 AI Studio(Nano Banana) / Google Flow에서 **3×3·3×4 연속 스토리보드 그리드 1장으로 한 번에 여러 장을 뽑아** 세계관·색감·구도 흐름을 먼저 검증한 뒤, `node scripts/media-craft-tools.mjs split-grid`로 컷별 분할해 필요한 컷만 업스케일/Omni `--first` 영상화로 넘긴다(참고 원리: `knowledge/ai-craft-research-2026-11-21.md`).
- **키이미지 올인(Nano Banana 리롤 → Omni 절약)**: Omni 무료 웹은 하루 약 6회 한도가 있다. 영상에서 한도를 태우지 않고, 무료 여유가 큰 Nano Banana 단계에서 세계관·단일 광원·색감 톤을 잡은 **키이미지(앵커) 1장** 또는 **연속 스토리보드 그리드**를 충분히 뽑아 검증한 뒤 영상으로 넘긴다.
- **일관성 확보(필요 시)**: 같은 인물·핵심 소품이 여러 컷에 나올 때 `6면 시트`(정면·반측면·측면·뒷면·아래·위)를 함께 활용한다.
- **2단계 참조 + 무텍스트 생성**: 장면 그림과 영상 생성(`--first` / `--last` / `--ref`)에 앵커 이미지를 연결하고, 소품·배경의 미세 텍스트·로고·스티커는 프롬프트에서 금지해 글자 뭉개짐을 막는다. 코드 레이어에 얹을 컷아웃 에셋은 가장자리가 직선으로 잘리지 않게 여백/테두리를 명시한다.
- **노드 계보 & 3대 부분 수정 & 열화 리셋**:
  - 모든 생성물 옆에는 `.prompt.json`과 버린 테이크(`assets/takes/`)를 남겨 어디서 어떤 변수 하나를 바꿔 뻗었는지 추적한다(`--parent <직전파일> --changed-var "<바꾼 변수>" --status candidate|chosen|rejected`, 조회: `node scripts/media-craft-tools.mjs lineage --dir <폴더>`).
  - 수정 시 처음부터 무작정 다시 뽑지 않고 **① 문제 프레임 캡처(`extract-frame`) → 이미지 부분 수정 → `--first` 재영상화 ② 앵글 전환 생성 → 베스트 프레임 캡처 → 재영상화 ③ 4회 이상 수정으로 열화되면 이미지를 LLM에 넣어 프롬프트로 역변환 후 처음부터 새로 생성(Fresh Generation)** 한다. 그리드/시트 분할(`split-grid`)·레퍼런스 컷(`extract-ref-clip`)도 필요 시 `scripts/media-craft-tools.mjs`로 실행한다.
- **저화질 선별 & 선택적 수용**: 핵심 동작은 `360p`로 먼저 확인하고 합격 프롬프트만 `1080p` 본생성한다. 시청자 시선이 머무는 핵심 단어·입 모양·주인공 오류는 고치되, 0.5초 스쳐 가는 배경 미세 오차에 일일 한도를 다 쓰지 않는다.
- **워터마크 4방 모서리 검수 (불변)**: 최종 화면에 워터마크 0px 노출만 고정하고, Flow·Gemini 앱 등 워터마크가 찍히는 도구는 장면에 따라 2가지 중 선택한다. ① **사전 여백 + 자동 크롭**(전체 화면 실사 기본: `crop-watermark` 9:16 하단 12.5%·16:9 우측 12.5% 중앙정렬) 또는 ② **원본 화질 보존(`--no-crop`) + 편집 디자인 덮개**(쇼츠 하단 12~15% 전체 띠·카드 액자·롱폼 분할 설명 카드 — 구석 스티커/고정 로고 및 유튜브 UI 방치 금지). 두 방식 모두 반입·렌더 후 4방 모서리 확대(`check-corners`)로 잔상 0px를 직접 눈으로 확인한다.

### 2. 후반 휴먼터치 (`HyperFrames` + `ffmpeg` + 사운드, 85점 → 완성)
AI 생성본만 이어 붙이면 85점에서 멈춘다. 마지막 디테일을 후반 레이어에서 끌어올린다.
- **HyperFrames 모션 감도**:
  - 뚝 멈추는 직선 이동 대신 감속 여운(`Easy Ease` 커스텀 이징), 덩어리 통이동 대신 요소별 시간차(Stagger)·반 박자 팔로우스로(Follow-through), 컷 사이를 잇는 연결 요소와 절제된 카메라 워킹.
  - 무맥락 장식 도형·과도한 모션 블러·불꽃/연기/스파클 파티클 남발을 피하고, 한·영 정보 위계를 분명히 나눈다.
  - 움직임 원리 참고: `npx hyperframes catalog --query "<동작>"` (무작위 값·실시간 물리 대신 시간 값 결정론적 코드로 작성).
- **8bit 톤/질감 통일 & 리듬 (`ffmpeg` · `scripts/media-craft-tools.mjs`)**: 서로 다른 AI 클립의 색온도·노출 단차를 공통 톤/미세 그레인으로 맞추고(`unify-tone`), 필요 시 BGM 비트·발화에 맞춰 클립 속도를 미세 조정한다(`detect-beats`).
- **사운드 4층 믹싱**: 나레이션(TTS) + Omni가 만든 원본 환경음(낮은 볼륨으로 유지, 불필요할 때만 `--mute`) + `npm run music`(Lyria 3.5 BGM, 더킹 + BPM 비트 맞춤) + 용도별 효과음(전환·강조·팝업 — 시청자가 놀라지 않는 낮은 볼륨 상한 준수).

### 3. 렌더 전 검수 (객관 수치 + 눈 확인)
- `npx hyperframes lint`, `npx hyperframes check`, `npm run check-terms -- videos/<프로젝트>` 통과.
- 브라우저/콘택트시트에서 직접 눈으로 확인: 정면 아이레벨·슬라이드 고착 여부, 얼굴/손/글자 열화, 컷 간 톤 단차, 글자 겹침·가림 여부. 가능하면 레퍼런스 대비 컷 밀도·화면 변화량 등 수치도 함께 대조한다(`compare-visual-metrics`).
