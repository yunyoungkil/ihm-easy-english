    - 해결: `isShorts` 판정 분기로 쇼츠 카드는 다크 프레임(`background: #000; height: 210px; display: flex; justify-content: center;`) 내에 `aspect-ratio: 9/16; object-fit: contain;`으로 렌더링하여 9:16 세로 썸네일의 글자와 이미지가 1픽셀도 잘리지 않도록 완벽 보존. 롱폼 카드는 `width: 100%; aspect-ratio: 16/9; object-fit: cover;`로 16:9 가로 비율 유지.
    - 공개 롱폼 카드에 실측 CTR 연동: `gDashboard.videoReachManual` 데이터를 매핑하여, 이미 공개된 롱폼 카드 하단에 `📊 최근 CTR N.NN% (N,NNN회)` 칩을 자동 표출.
  - **Studio CTR 트래커 컴팩트 데이터 테이블 탑재 및 비주얼 팝업 연동**:
    - 기존 문제: 80여 개 영상의 노출/CTR을 카드 뷰로만 보여주어 스크롤이 지나치게 길고 데이터 간 비교가 어려웠음.
    - 해결 (`ui-ux-pro-max` 인텔리전스 반영):
      1. 기본 뷰를 `[📋 컴팩트 목록 (권장)]` 테이블로 개편: 고밀도 OLED 다크 테이블 구조로 포맷 태그, 제목, 노출수(소표본 1,000회 미만 `🌱 초기 반응 수집 중` 서브라벨 자동 표출), 최신 CTR %, 직전 대비 증감(▲▼), 분석 구간, 연결 상태를 한눈에 파악.
      2. 150ms 비주얼 팝업 프리뷰: 테이블 행의 미니 썸네일에 마우스 오버 시 `hover-pop` 레이어가 부드럽게 떠올라 원본 썸네일을 즉시 확인할 수 있도록 구현 (공간 효율 + 시각적 확인 동시 달성).
      3. 기본 필터 `LONGFORM` 적용: 노이즈가 많은 쇼츠 대신 롱폼을 우선 정렬해 실질적인 CTR 개선 액션에 집중 유도.
      4. `[🖼️ 카드 뷰]` 토글 및 상태 유지(`localStorage`) 지원. 카드 뷰에서도 쇼츠 9:16 / 롱폼 16:9 개별 프레임 적용으로 잘림 해결.
