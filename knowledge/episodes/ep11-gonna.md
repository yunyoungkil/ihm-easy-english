## ✅ 블로킹 이슈 해결됨 (2026-09-04)

**원래 문제(2026-09-03 발견)**: 나레이션 음성이 여성(HeyGen `tts_provider: heygen`,
`voice_id: 05f19352e8f74b0392a8f411eba40de1` = Marcia)인데 채널 기준 인물은 남성 — 화면·목소리
성별 불일치. `videos/ep11-longform-faceless/`가 "채널 기준 인물=남성" 결정(2026-09-01)보다
먼저(8/27~29) 만들어져서 당시엔 성별 기준 자체가 없었던 것으로 추정.

**해결**: EP12에서 확정된 기준을 그대로 적용 — 나레이션 엔진을 HeyGen에서 **구글 Gemini(Charon)**로
전면 교체(EP6~10, EP12와 동일 목소리). 상세 작업:
1. `scripts/tts-config.mjs`(채널 고정 보이스, 얼려둔 파일)를 직접 건드리지 않고, 프로젝트 로컬
   `scripts/regen-tts-gemini.mjs`를 새로 작성해 그 export들(`synthesize`/`pcmToWav`/
   `estimateCost`/`appendLedger`)을 재사용 — 13개 씬 전부 재생성. 실제 비용 **₩199**(0.14달러,
   사전 견적 ₩174와 근접). 생성 중 1건 `finishReason: SAFETY` 거짓 양성 발생 — 재시도로 해결
   (내용 문제 아님, 알려진 API 불안정성).
2. Gemini는 HeyGen과 달리 단어별 타임스탬프를 안 줌 → `words: []`로 저장. 이 프로젝트가 쓰는
   `faceless-explainer` 파이프라인의 `captions.mjs`는 "단어 없음 → 합법적 스킵"을 이미 지원해서,
   **캡션 제거를 위해 별도 작업이 필요 없었다** — 오래된 `compositions/captions.html`/
   `caption_groups.json`만 직접 삭제하니 `assemble-index.mjs`가 자동으로 캡션 트랙을 뺐다
   (EP12와 동일한 "Gemini TTS는 단어별 자막 안 씀" 결정 — [결정 기록](../decisions/2026-09-04-no-word-level-captions-with-gemini-tts.md)).
3. `faceless-explainer` 워크플로 스크립트로 나머지 파이프라인 자동 처리 — 새 오디오 길이를
   `audio.mjs sync-durations`로 `STORYBOARD.md`에 반영 → `assemble-index.mjs`로 `index.html`
   재조립(총 길이 214.24초 = 3:34) → `transitions.mjs inject`로 씬 전환 10개 재적용. 수작업으로
   타이밍을 직접 계산하지 않고 기존 프로젝트 스크립트를 그대로 재사용함.
4. `npm run check` 0에러, 스냅샷으로 실제 화면 확인(시즌2 흔적 없음, Frame 13 새 마무리 정착 확인)
   후 재렌더 완료.

**"시즌2" 표기도 같이 제거**: Frame 1 eyebrow("이해하면 쉬운영어 · 시즌2" → "이해하면 쉬운영어"),
Frame 2의 "시즌2 · EP1" pill(완전 삭제, 워드마크만 남김), 나레이션 "오늘부터 시즌2 —" → "오늘은".
Frame 13의 "그럼 WANT TO는요? 다음 영상에서 확인하세요"(다음 편 예고, 안 닫힌 결말)도
"다음에도 여러분이 자주 헷갈리는 발음, 또 풀어드릴게요"로 정정 — 특정 소재를 예고하지 않는
단편 방침, EP12 Frame 10과 동일한 정정 패턴.

## ✅ 제목·썸네일 개정 (2026-09-04)

원래 확정 제목("GOING TO를 원어민처럼 읽으면 GONNA가 됩니다 — 그럼 WANT TO는요?")도 같은 이유로
깨짐 — 실제 WANT TO는 다음 편(EP12)으로 이어지지 않고 전혀 다른 소재로 갔다. 썸네일 **이미지**
자체엔 WANT TO 텍스트가 없어서(그림은 GOING TO/GONNA만) 이미지는 안 건드려도 됐지만, 제목은
수정 필요.

새 제목·문구는 감으로 정하지 않고 실제 데이터로 골랐다 — `market-demand.json`의 "영어 듣기 안
들리는 이유" 키워드 버킷(아웃라이어 실측 28.2배)을 근거로 5안을 뽑아 사용자가 A안 선택:
- **제목**: `미드 볼 때 GOING TO가 하나도 안 들리는 이유`
- **썸네일 문구**: `사실 GONNA로 들렸던 겁니다`
- **뱃지**: `🎧 리스닝 고민 해결`

대시보드 A/B 시뮬레이터 워크벤치에 위 값을 서버 상태로 미리 채워둠(`POST /api/ab-simulator/state`) —
사용자가 대시보드에서 바로 이어서 썸네일 이미지만 새로 생성하면 됨. 상세: `BRIEF.md`.
