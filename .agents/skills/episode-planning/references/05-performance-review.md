# Phase 11: 공개 후 성과 리뷰 & 피드백 시스템

이 문서는 영상 공개 후 7일/28일 시점에 과거 기획 당시의 예측과 실제 성과를 정밀 비교하여 다음 기획에 되먹이는 워크플로우(Phase 11)를 규정합니다.

---

## 1. 개요 및 원칙

- **목적**: 기획 가설을 사후 검증하여 "어느 분석이 맞았고 어느 가정이 틀렸는지"를 명확히 밝히고 채널 성공 공식을 누적합니다.
- **실행 시점**: 공개 후 **7일** 및 **28일** 경과 시점 (Phase 1 항목 5에서 자동 확인 또는 사용자 요청 시).
- **비교 원칙**: **같은 방식(강의/듣기)과 형식(롱폼/쇼츠)끼리만 비교**합니다 (강의형 롱폼과 듣기형 쇼츠 혼합 비교 금지).
- **표본 정직성**: 우리 채널은 영상 수가 적으므로 0.1% 단위의 성장을 인위적으로 조작/약속하지 않고, "틀린 가정을 하나씩 지워 나가는 과정"으로 기록합니다.

---

## 2. 리뷰 절차

1. **라이브 데이터 조회**: `/api/sync` 호출 직후 `/api/dashboard`에서 해당 영상의 조회수, CTR, 시청 지속률을 확인 (추정값 입력 금지).
2. **예측과 비교**: `REVIEW.md`에 기획 당시 기록해 둔 "예측" 칸 아래에 실제 수치를 나란히 기재.
3. **가설 및 클러스터 판정**: 맞았던 가정과 틀렸던 가정을 분리하고, Phase 3 경쟁 채널 스캔의 클러스터 판정이 유효했는지 점검.
4. **유튜브 Test & Compare 결과**: A/B/C 제목·썸네일 승자 확인 및 기록.
5. **확정 vs 가설 분리**:
   - **확정**: 2편 이상에서 동일하게 재현된 성공 요인.
   - **가설**: 1편에서만 관찰된 단일 현상.
6. **성공 패턴 승격 (`success-patterns.json`)**:
   - 확정된 교훈만 `data/youtube/success-patterns.json`에 업데이트.
   - 업데이트 전 반드시 사용자에게 검수 및 승인을 받음.
7. **차기작 반영 사항 도출**: 다음 기획 Phase 4에서 근거로 삼을 핵심 교훈 1줄을 확정.

---

## 3. REVIEW.md 마크다운 템플릿

```markdown
# REVIEW — <프로젝트명> (공개 <YYYY-MM-DD>)

## 유형 (Phase 2에서 선택, 수정하지 않음)
- 방식: <강의 | 듣기 | 혼합>
- 형식: <롱폼 | 쇼츠 | 세트>

## 예측 (Phase 4에서 기록, 수정하지 않음)
- 후보: <제목 앞부분>
- 근거 클러스터(판정 등급): <...>
- 근거 영상: <채널 · 제목 앞부분 · 배율 · 올린 지>
- 예상: 우리 최근 조회 중앙값 대비 <범위> — 이유 <한 줄>

## 실제 (Phase 11 리뷰, 라이브)
- 출처: /api/sync 호출 <시각>, /api/dashboard
- 조회수 / CTR / 시청 지속률: <값 또는 "데이터 없음">
- 공개 후 경과: <7일 | 28일>

## 판정
- 예측과 실제: <맞음 / 틀림 / 판단 보류> — <이유>
- 클러스터 판정(Phase 3): <맞음 / 틀림 / 판단 보류>
- 맞았던 가정: <...>
- 틀렸던 가정: <...>
- A/B 승자(제목·썸네일): <승자 / 없음>

## 확정 vs 가설
- 확정(2편 이상에서 확인): <...>
- 가설(1편): <...>

## 다음 영상에 적용할 것
- <한 줄>
```

## 4. 부록: 대시보드 자동 추천과 이 워크플로우의 차이

| 비교 항목 | 대시보드 자동 추천 (`idea-board.mjs`) | 이 에피소드 기획 워크플로우 |
|---|---|---|
| **데이터 소스** | `data/youtube/*.json` 캐시 스냅샷 | 매번 `/api/sync` 라이브 재조회 + 실시간 채널 스캔 + 웹 검색 |
| **유형 분류** | 일괄 처리 | 방식(강의/듣기/혼합) × 형식(롱/쇼츠/세트) 사전 결정 |
| **제목/썸네일 평가** | Gemini AI 가상 CTR 점수 | 검색의도·호기심갭·구체성 체크리스트로 직접 판단 |
| **중복 방지** | `idea-board-history.json` 단순 조회 | 실제 카탈로그 및 프로젝트 폴더 라이브 전수 스캔 |
| **성과 피드백** | 매트릭스 AI 진단 (유료 호출) | 예측과 실제를 `REVIEW.md`에 나란히 대조, 2편 이상 재현된 공식만 승격 |
| **진행 방식** | 버튼 클릭 일괄 생성 | **11단계별 순차 진행, 매 단계 사용자 명시적 승인 대기** |
