# REVIEW — ep24-shorts-sheep-ship (손 그림 반영 후 다른 PC에서 렌더링)

## 유형
- 방식: 듣기 퀴즈
- 형식: 쇼츠 (44.65초)

## 예측 (공개 전 기록, 수정하지 않음)
- 시험 기준: 공개 7일 안에 500회 (`knowledge/now.md`)
- 참고: 최근 쇼츠 5편의 누적 조회 중앙값 1,202회(2026-11-07 API). 쇼츠 공개가 65일 끊긴 뒤 첫 편이라 예전 수치를 그대로 기대하지 않는다.
- 롱폼 연결은 유입 경로 `SHORTS_CONTENT_LINKS`로 본다. 기준값은 쇼츠 조회 52,546회에 33회(2026-06-01~11-07).

## 제작 메모 (2026-11-07)

### 정한 것
- 구성: 소리 → 그림 고르기 3문제 → 입 모양 → 마지막 5초 롱폼 안내.
- 스타일: 웜크림 네오브루탈리즘. 그림은 화면의 약 48%를 차지한다.
- 음성: 영어 소리는 원어민 음성만 쓴다. 세 번째 문제만 여성 음성이다(`m_w24_fill`은 실제 소리가 0.16초뿐). 파일 이름의 `m_`이 항상 남성은 아니다. `m_w23_feel`, `m_w24_fill`은 약 250Hz로 여성 음역으로 측정됐다.
- 음량: 남성 단어 음성이 나레이션보다 약 9dB 작아, 단어마다 최고 음량을 -4dB로 맞췄다(배율 0.76~2.34).
- 배경음: EP21과 같은 곡의 20초 지점부터 사용, 볼륨 0.06, 나레이션 구간 더킹 적용. 볼륨은 규칙 충돌(6% vs 8~10%) 중 HyperFrames 기본 규칙을 따랐다.
- 폰트: Noto Sans KR(OFL)을 자주 쓰는 한글 2,350자로 줄여 넣었다(0.8MB).

### 측정한 것
- `npx hyperframes check`: 통과. 오류·경고 0건. 정보 6건은 장면 전환 순간의 겹침이다.
- `npm run check-terms`: 금지어 없음.
- 그림 4장: 글자 없음, 네 모서리 로고 없음(대비를 높여 눈으로 확인).
- 나레이션: 음성 인식 결과가 대본과 일치. "쉽"만 "시입"으로 인식됐다.
- 원어민 단어: 음성 인식 결과가 파일 이름과 일치.
- 화살표: 사용자 폰 캡처와 겹쳐 채널 이름 바로 위, 링크 가운데쯤을 가리키는 것을 확인했다.
- 길이: 44.65초. 마지막 안내 4.92초.

### 아무도 확인하지 않은 것
- **소리를 사람이 듣지 않았다.** 다음을 들어 봐야 한다.
  - 7.1~9.5초 "흔히 둘 다 쉽이라고": "시입"으로 들리지 않는지
  - 10.7초, 11.7초 sheep과 ship: 길이 차이가 "길이보다" 설명과 어긋나지 않는지
  - 19초, 28초 부근: 단어가 짝끼리 다르게 들리는지
  - 전체: 효과음과 배경음 크기
- 카드 반응 시각(`spot`)은 소리 크기로 추정한 값이라 약 0.15초 어긋날 수 있다.
- 렌더링 전이라 완성 파일의 음량은 재지 못했다. 렌더링 후 `npx hyperframes audio`로 잰다.

### 가장 약한 장면
입 모양 장면(29~39초). 그림만으로는 입꼬리와 턱 차이가 크지 않아, 카드 강조와 뱃지에 많이 기댄다.
