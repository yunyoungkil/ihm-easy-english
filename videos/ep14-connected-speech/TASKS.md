## 2026-09-08 (이어서) — Frame 7(linking-diagram--bounce) 제작

MADE/IT은 자음+모음 경계 구조가 명확해서(WE와 다르게) Frame 5의 고정폭 letter-column/letter-tag
구조를 그대로 재사용, D는 APPLE로 넘어갔던 N과 달리 **이동하지 않고 제자리에서** `y`+`scale`만으로

시각적 구분 원칙 준수). D·I 하이라이트는 accent-exception 빨강, 결과 캡션 "메이릿"은 다른 프레임과
동일하게 accent-pronunciation 파랑 유지(다이어그램 강조색만 패턴 종류별로 다르고, "이게 실제
소리다"라는 파랑의 의미는 전 프레임 공통으로 고정). Frame 6의 "루" 부분 강조 기법을 재사용해
"릿" 부분만 나레이션이 ㄹ 소리를 짚을 때(36.87s) 별도 펄스.

**버그 2건 발견·수정**: (1) `npm run check`가 `overlapping_gsap_tweens` 경고를 잡아냄 — 바운스의
두 번째 단계(착지) 트윈을 절대시각으로 하드코딩했더니 첫 단계 트윈의 계산된 종료 시각과 부동소수점
오차로 미세하게 겹침 — 절대시각 대신 `"+=0"`(GSAP 상대 위치 문법, "직전 트윈이 끝나는 정확한
시점")으로 바꿔 해결(앞으로 같은 요소에 연속 트윈을 이어붙일 땐 절대시각 대신 이 패턴을 기본으로
쓸 것). (2) `npm run check`의 Contrast 검사가 태그 텍스트(0.95cqw, 작은 글씨라 WCAG AA 기준
4.5:1 필요)에서 순수 빨강(#FF0000, 4.11:1)이 기준 미달이라고 잡아냄 — 제안된 `#FF3333`으로 교체.
스냅샷으로 전 비트 확인 완료.
