# EP10 Shorts A — Broadside V3

Broadside의 원형을 재해석하지 않고 9:16 학습 영상에 적용한다. 검정과 오렌지 두 면, 큰 글자 한 덩어리, 넓은 여백, 얇은 선만 사용한다.

## Rules

- 한 프레임에는 하나의 display moment만 둔다.
- 한국어는 Barlow와 같은 무게의 Noto Sans KR 900으로 대응한다.
- 영어와 숫자는 Barlow 900, 작은 정보는 IBM Plex Mono만 사용한다.
- 색상은 `#111111`, `#E85D26`, `#F0ECE5` 외에는 사용하지 않는다.
- 문장이나 목록은 최대 세 항목으로 제한한다.
- 전체 화면 장식, 아이콘, 카드, 그림자, 둥근 모서리를 사용하지 않는다.
- V3는 정적 디자인 비교판이며 모션은 비워 둔다.
