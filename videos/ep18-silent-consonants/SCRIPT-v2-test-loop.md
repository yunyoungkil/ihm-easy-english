# SCRIPT v2 (테스트 루프 포맷 시안) — ep18-silent-consonants 소재 재구성

**이건 발행된 EP18을 덮어쓰는 게 아니라, "롱폼을 설명형 → 테스트형으로 완전히 바꾸면 어떤
모습이 되는가"를 확인하기 위한 별도 시안이다.** 기존 SCRIPT.md는 그대로 둔다.

## 왜 EP18 소재로 시범했는가

채널 조회수 상위 영상 대부분이 "테스트" 포맷(발음 테스트/10초 확인 시리즈)이었고, EP18
자체에도 이미 Frame 12~13(5:24~6:13, "문장 확장 1/2")에 이 방식의 씨앗이 있었다 — 사용자가
직접 지목한 지점. 그런데 그 구간은 전체 414초 중 49초(12%)뿐이었고, 앞 114초(27%)는 순수
설명(도입/인트로/빅퀘스천/반전/원리)이었다. 이번 시안은 그 비율을 뒤집는다.

## 시간 배분 — 기존 대비

| 구간 | 기존 EP18 | v2 시안 |
|---|---|---|
| 훅+원리 압축 | 114초 (27%) — 5개 프레임 | **40초 (10%)** — 2개 프레임 |
| 단어별 3회 낭독 코칭 | 112초 (27%) | **삭제** — 코칭 없이 바로 테스트로 흡수 |
| 반전 트리비아 | 29초 (7%) | 유지 (짧게) |
| 테스트/퀴즈 루프 | 70초 (17%, 6단어) | **약 220초 (53%), 18~20단어** |
| 문장 테스트 | 49초 (12%, 2문장) | 루프 안에 매 단어마다 내장 |
| 요약+클로징 | 41초 (10%) | 유지 |

핵심 변화: 기존엔 "설명 → 코칭 낭독 → (나중에) 퀴즈"였던 것을, "원리 1문장 → 곧장 단어별
테스트 루프(읽기? 뜻? 문장에서 어떻게 쓰지?) 반복"으로 바꾼다. 설명은 사라지는 게 아니라
정답 공개 뒤 **1문장짜리 원리 태그**로 압축돼 각 단어에 따라붙는다.

## 테스트 루프 1세트 구조 (모든 단어 공통, 약 9~11초/단어)

```
[0~3초] 철자 제시, 화면 정지. 나레이션: "다음 단어, 소리 내서 읽어보세요." (또는 무음 3초 게이지만)
[3~5초] 정답 공개: 묵음 철자 사라짐 + 발음 표기 등장. 나레이션이 정확한 소리로 읽어줌.
[5~7초] 뜻 태그 등장 (한글 1단어). "이런 뜻이에요."
[7~9초] 그 단어가 들어간 초단문 1개 등장 + 발화 ("I hurt my knee." 식) — 설명 없이 노출만.
[9~11초] 즉시 다음 단어로 크로스페이드. 숨 고르는 구간 없음.
```

이 루프가 KN/MB/WR 각 카테고리당 6~7단어씩, 총 19단어 반복된다. 사용자가 말한 "읽을 수
있는지 / 뜻을 아는지 / 문장에서 언제 쓰는지 테스트 후 계속 듣게 하고"가 정확히 이 4단계
(읽기 테스트 → 정답 → 뜻 → 문장 노출 → 다음)에 대응한다.

## Line 4 — KN 테스트 루프 (신규, 7단어 × ~10초 = 약 70초)

## 예상 총 러닝타임

15 + 11 + 15 + 70 + 60 + 60 + 20 + 15 + 21.64 ≈ **287.64초 (약 4분 48초)**

기존 414초(6분 54초) 대비 약 30% 짧아진다 — 설명을 걷어내고 테스트 밀도를 높인 결과다.
쇼츠에서 검증된 "10초 안에 하나씩 확인시켜주는" 리듬을 롱폼 안에 19번 반복하는 구조라,
이론상 매 10초마다 새로운 확인/도파민 포인트가 생겨 11초 이탈 구간을 여러 번 통과시킬
가능성이 있다 — 다만 이것도 추정이고, 실제로는 이 영상 하나를 만들어 업로드한 뒤 리텐션을
봐야 확인된다.

## 다음 확인이 필요한 지점

1. **말하는 사람이 없다는 전제**: 이 루프는 나레이션이 "읽어보세요 → 3초 → 정답"을 반복하는
   구조라, 기존 Line 6~8의 "함께 소리 내보실까요?" 코칭 톤보다 훨씬 건조하고 빠르다. 이 톤이
   맞는지 확인 필요 — 너무 기계적으로 들릴 위험이 있다.
2. **문장 노출을 "설명 없이 노출만"으로 처리하는 게 맞는지**: 사용자 메시지가 "문장을 언제
   사용하는지 테스트"라고 했는데, 이번 초안은 문장을 테스트가 아니라 그냥 보여주기만 했다.
   진짜 "문장에서 언제 쓰는지"까지 테스트하려면 예를 들어 두 문장 중 맞는 걸 고르게 하는
   식으로 한 단계가 더 필요할 수 있다.
3. 이 구조가 마음에 들면 다음 단계는 HyperFrames 컴포지션(카드/타이밍)을 이 19단어 루프에
   맞게 새로 짜는 것 — 기존 ep18-silent-consonants 프로젝트를 덮어쓸지, 새 프로젝트로
   분리할지도 정해야 한다.
