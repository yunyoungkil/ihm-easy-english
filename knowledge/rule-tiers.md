# 규칙의 세 층 (2026-11-13, 사용자 확정 전 초안)

**전체 문서 분류(489행, 충돌 27건, 사용자 결정 필요 8개)는 `knowledge/rule-tiers-full-draft.md`.** 이 파일은 AGENTS.md 기준 요약이다.

비교 시트로 컨셉을 시험하려면 컨셉을 못 박는 규칙이 있으면 안 된다. 규칙을 세 층으로 나눈다. **AGENTS.md와 주요 문서 기준으로 나눈 것이고 `thumbnail-strategy.md`·`production-rules.md`의 세부 규칙은 아직 전수 분류하지 않았다. 분류 안 된 규칙은 기본값으로 본다.**

## 0. 전제 (사용자만 바꾼다, 2026-11-13)
시청자는 3060 국내 거주 영어 학습자다. 불변 목록과 같은 무게이며 데이터(시청자층 연령 등)나 비교 시트가 바꾸지 못한다. 근거와 검토: `knowledge/decisions/2026-11-13-experiment-loop.md`, `knowledge/handoff/2026-11-13.md` "Opus 검토: 시청자 연령" 절.

## 1층 불변 (사용자가 정한다, 시트가 못 바꾼다)
사용자는 8·9번을 고쳤고 나머지는 이의 없음. **1~9번은 2026-11-13 사용자가 최종 확정했다.** 10~13번은 9개 밖 후보에서 2026-11-13 사용자가 승인해 올렸다(5번의 가짜 통계·길이 표기도 같은 때 승인).
1. 비교 시트(썸네일 선택 포함)·렌더·업로드는 사람이 승인한다. 승인은 품질 판단이 아니라 안전 확인과 취향 반응이다(2026-11-15 방향 점검, 결정표 `knowledge/decisions/2026-11-15-direction-audit-decisions.md` 8번).
2. AI 워터마크·로고 금지, 반입 전 네 모서리 확인.
3. 대본의 사실 확인(`FACT-CHECK.md`) 없이 음성을 만들지 않는다.
4. 하지 않은 경험·가짜 댓글을 지어내지 않는다. 경쟁 영상의 경험은 출처를 밝히거나 일반 상황으로 바꿔 쓴다.
5. 성과 숫자는 코드가 데이터에서 계산한 것만 쓴다. 작은 표본은 "가설" 표시를 붙여 쓰고 확정은 단계를 거친다. 가짜 통계를 쓰지 않고, 제목·썸네일의 길이 표기("20분 연속" 등)는 실제 영상과 맞을 때만 쓴다.
6. 자동 업로드는 `decideNextUpload` 하나만 통과한다.
7. 같은 틀을 찍어 내지 않는다(수익 창출 정책). 매 편 그 소재에만 있는 코너가 있어야 한다.
8. **롱폼만**: 마지막 7~10초(엔드스크린이 들어가는 구간)는 화면 중앙을 비운다. 카드류는 엔드스크린 요소 크기 이하이거나 정확히 맞고 겹치지 않는다(크기는 `production-rules.md`). 쇼츠에는 엔드스크린이 없다(2026-11-13 사용자). 쇼츠는 롱폼으로 잇는 연결 표시만 하고 이 규칙을 받지 않는다.
9. 일반 시청자가 완전히 모를 학술 전문 용어를 쓰지 않는다(경쟁 영상의 용어는 쉬운 말로 풀어 쓴다).
10. 경쟁 영상의 대본·그림·문구를 베끼지 않는다(저작권·수익 창출 정책).
11. 예측 칸은 영상 공개 뒤에 고치지 않는다(고치면 예측이 의미 없어진다).
12. 돈이 드는 호출은 원화 견적을 먼저 알리고 사용자 승인을 받는다.
13. 공개 일정을 올리기 전에 확인한다.
14. **쇼츠 상단 0.5초 훅 글자 노출 필수 & 모바일 최소 글자(34px) 준수 (2026-11-17 사용자 확정)**: 쇼츠 피드 이탈을 막기 위해 상단 안전구역 훅 글자 노출은 필수 가드레일이다. 단, 시각적 형태(검은 띠 고착 탈피)는 2층 기본값 및 3층 실험 변수로 유연하게 진화시킨다.
15. **한글 작성 시 Korean Skills(humanizer, grammar-checker, style-guide) 필수 적용 (2026-11-17 사용자 확정)**: 나레이션, 대본, 제목, 썸네일 카피, 설명글, 태그, 고정 댓글 등 한글로 된 모든 텍스트 작성·교정 시 AI 번역투/기계적 문맥 배제(humanizer), 맞춤법/띄어쓰기(grammar-checker), 채널 어조 일관성(style-guide)을 필수로 거친다. 특히 나레이션 대본 작성 시 글자 수나 박자는 '4글자, 5글자'처럼 아라비아 숫자로 표기하거나 말하지 않고, '네 글자', '다섯 글자', '세 글자', '한 박자'처럼 한글 고유어 입말 발음 그대로 적는다.

승인 지점(2026-11-13 사용자): 비교 시트 승인 1번(기획·제목·대본)을 받으면 이어서 렌더 → 업로드 순으로 승인한다. **시트에서 고른 썸네일을 썸네일 승인으로 인정한다(2026-11-13 사용자 결정).** **2026-11-15 코드 반영 완료**: 시트가 `approved`이고 패키지 `thumbnail.jpg`가 시트에서 고른 첫 시안과 같은 파일이면 `package-from-sheet.mjs`가 패키지 폴더에 `sheet-thumbnail-approval.json`(지문 포함)을 쓰고, `decideNextUpload`는 이 기록의 지문이 현재 썸네일과 같을 때만 통과시킨다(파일이 바뀌면 승인이 풀리는 성질 그대로). 시트가 없는 패키지는 지금처럼 대시보드 승인이 필요하다.

## 2층 기본값 (근거 없을 때의 출발점, 시트가 근거를 적으면 바꾼다)
- BGM 볼륨 6%에서 시작(반복 듣기형은 8~10%도 가능), 나레이션 더킹
- 썸네일·제목 클릭 심리 최우선 & 형식 비고정(2026-11-17·11-23 사용자 확정): "5단어 이하", "글자 수 제한", "제목·썸네일 겹침 금지", "3요소 제한", "1인칭 금지", "얼굴 필수" 같은 형식 공식을 하드코딩하지 않는다. 클릭이 일어나지 않으면 영상 완성도·시청 시간도 소용없으므로, 1초 안에 감정 불씨와 풀리지 않은 질문(미완결 고리)이 켜지는지를 최우선으로 삼는다. 정답 스포일러·교과서 목차 라벨·사연 없는 껍데기 표정은 경계하며, 같은 분야뿐 아니라 타 분야 설명 채널·플랫폼 밖에서 더 강한 클릭 심리를 AI가 주도적으로 계속 발굴·적용하고 실제 클릭률·시청 지속으로 증명한다.
- 제목: 검색 의도·구체 상황·시청자 찔림을 살려 다각도 앵글로 3안을 제시한다(ABC 고정 공식 폐지). 과도한 이모티콘·느낌표·해시태그 도배는 지양한다. 노출이 작은 시기(롱폼 7일 노출 중앙값 47회 등)에는 스튜디오 비교 테스트 판정 불능이 잦으므로 업로드 전 문구 3~4개 사전 비교를 기본으로 두고, 스튜디오 비교 테스트는 노출이 커진 뒤 본격 가동한다.

- 나레이션 톤: 차분한 실전 파트너, 습니다체, 문장 끝맺음 다양하게
- 옛 고정 캐릭터 아바타(파란 볼캡+티셔츠) 미사용(2026-10-28 중단, 2층 기본값 — 일반 실사·일러스트 인물 장면은 중단 대상이 아니며 3층 실험 변수로 자유 활용, 2026-11-21·22 정합)

- 퀴즈 질문 화면에 정답을 보이지 않는다, 1음절 영어 단어를 한글로 쪼개 쓰지 않는다(2026-11-13 기본값으로 둠)
