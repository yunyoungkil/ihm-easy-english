# 데이터 신뢰도와 한국 트렌드

## 목표

조사 데이터를 많이 쌓는 대신, 판단에 쓸 수 있는 데이터를 식별한다. 매일 YouTube 조사 탭을 가져오는 일과 한국에서 외국 콘텐츠·뉴스가 실제 화제가 됐는지 확인하는 일은 서로 다른 질문이다.

## 1. 자료 적합성 확인

| 확인 | 필요한 근거 | 불명확하거나 부적합할 때 |
|---|---|---|
| 무엇을 판단할 자료인가? | 소재 수요, 시청자 문제, 포장, 유지 등 소비 목적 | 소비처가 없으면 수집 확대를 보류하고 데이터 소비 지도를 대조 |
| 어디서 언제 얻었나? | 플랫폼·URL/영상 ID·게시/수집 시각·기간·언어·지역 | 출처·시점이 없으면 최신 근거로 쓰지 않고 격리 |
| 비교 단위가 같은가? | 영상 형식, 조회수 기간, 게시 후 경과일, 노출 정의·모집단 | 서로 다른 뜻의 값을 한 배율/기준선에 섞지 않음 |
| 비교 집단이 공정한가? | 같은 채널·형식 여부, 주제·길이·측정 창·선정 편향 | 큰 숫자라는 이유만으로 기준선에 넣지 않음 |
| 원본과 계산을 재현할 수 있나? | 입력 필드, 변환식·버전·분모·유효 표본 수 | 재현 불가면 판정에 사용하지 않고 참고만 함 |
| 결측·중복·실패가 구별되나? | 중복 영상, 결측 필드, 수집 오류, 선택 조건 | 낮은 성과로 오인하지 않도록 격리하거나 보류 |

상태는 사람이 이유를 이해할 수 있게 구분한다(예: 사용 가능, 참고, 검증 대기). 그 상태를 임의의 숫자 문턱이나 고정 분류표로 확장하지 않는다. 0·결측·실패는 정상적인 낮은 성과가 아니다.

## 2. 배율과 비교의 안정성

현재 저장소 문서에는 같은 채널·형식의 중앙값을 비교 기준으로 삼는 방향이 있다. 하지만 기준 집단 자체가 오염되거나 분모가 불안정하면 중앙값도 답이 아니다.

- 계산에 포함·제외한 영상과 사유, 원본, 측정 시점을 추적 가능하게 한다.
- 게시 기간이 다른 영상의 총 조회수를 그대로 나누지 않는다. 목적에 맞는 측정 창·정규화 방식을 정하고 정의와 버전을 기록한다.
- 표본 부족, 0/결측 분모, 극단값 편향이면 숫자를 꾸며내지 않고 비교 불가 또는 측정 대기로 둔다.
- 새 계산과 옛 계산을 한 순위·평균에 섞지 않는다. 각각 방법과 기간을 표시한다.
- 표시용 배율 하나가 채널 적합성이나 콘텐츠 품질을 자동 판정하지 않게 한다.

과거 감사 수치와 저장된 배율은 기준 시점과 계산 과정을 확인하기 전까지 현재 사실처럼 반복하지 않는다. 실제 오염 행을 재현해 어떤 리포트·시트·기준선에 영향을 주는지 확인한다. 원본은 보존하고 격리·재계산·백필 범위와 되돌리는 방법을 제안한다.

## 3. 한국 트렌드 확인

조사 탭은 YouTube 내부 관심의 입력일 뿐이다. 한국에서 관심을 얻은 외국 드라마, 영어권 유튜브, 해외 뉴스가 모두 조사 탭에 잡힌다고 가정하지 않는다. 반대로 해외에서 화제라는 이유만으로 한국 트렌드라 부르지 않는다.

검토할 때 발생 원천, 한국 내 관심 근거(한국어 보도·검색 관심·국내 플랫폼 반응 등), 영어 학습과의 연결, 우리 채널에서 얻을 가치, 확인 날짜와 유효성을 따로 살핀다. 어느 근거가 빠졌는지 표시한다. 한국 내 관심이 확인되지 않으면 한국 트렌드로 단정하지 않는다. 학습 가치가 약하거나 시의성이 지난 이슈는 대본에 억지로 넣지 않는다.

트렌드가 연결되는 방식은 소재 자체, 도입 사례, 제목·썸네일의 맥락 등 매번 상황에 맞춰 판단한다. 이를 고정 단계·양식으로 만들지 않는다. 원래의 학습 약속이나 브랜드를 해치면 채택하지 않는다.

## 4. 사실·권리·수집 부작용

해외 사건·인용·방송 정보를 원출처와 신뢰할 수 있는 교차 출처로 확인하고, 사실과 해석을 구분한다. 제목·썸네일이 미확인 내용을 확정적으로 과장하지 않게 한다. 원본을 번역·요약해 재현하는 데 그치지 말고 새로운 영어 학습 맥락으로 재구성한다. 이미지·영상·음성의 사용 권리와 민감성을 검토한다.

새 수집원에 유료 구독·API 비용·로그인 자동화·약관 제약이 있으면 수집기부터 만들지 않는다. 비용, 대안, 범위를 제시하고 승인 관문을 따른다. 문서만 보고 접근 권한을 추정하지 않는다.

## 5. 저장소 감사 시

knowledge/data-consumption-map.md와 코드에서 실제 소비처를 확인한다. 소비 지도는 일부 조사 데이터가 아직 사용처 없음으로 기록된 과거 기준이므로 지금도 그렇다고 단정하지 않는다. 데이터·리포트·계산 경로를 현재 브랜치에서 다시 추적한다. 수집 확대 전에 의사결정 소비처, 품질 검사, 실패 처리, 비용, 보관 및 삭제 범위를 설계한다. 구현을 요청받지 않았다면 분석과 제안까지만 한다.

완료로 판단하려면 수치에서 원본·계산으로 돌아갈 수 있고 부적합 자료가 정상 비교에 섞이지 않아야 한다. 트렌드 주장에는 한국 내 관심 근거와 확인 시점이 붙어야 한다. 불충분하면 판단을 보류한다.
