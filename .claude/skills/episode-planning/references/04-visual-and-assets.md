## 2. PHASE 9 — 3중 하이브리드 분업 판단 & 레퍼런스 분해

화면의 AI 템플릿 냄새를 없애는 출발점은 **"모든 걸 코드 상자로 그리거나, 모든 걸 영상 AI 한 번에 맡기지 않고 각 도구가 가장 잘하는 영역으로 나누는 것"** 이다.

| 장면 성격 | 주력 도구 | 이유 (2026-11-21~22 유튜브 94편 조사·실측) |
|---|---|---|
| **실사 상황, 인물 표정·대사, 실제 사물·공간의 유기적 동작** | **`Omni 1.2 Flash`** (`npm run video`) | 코드로 만들 수 없는 진짜 질감·자연스러운 호흡·환경음·한국어 립싱크까지 생성 |
| **종이 콜라주, 찢어진 질감, 실물 컷아웃 레이어 모션** (입 구조, 단어 분해 등) | **`Nano Banana 2.1`** (`npm run image`) + **`HyperFrames`** 레이어 애니메이션 | 이미지 AI의 실물 질감 + 코드의 정밀한 레이어 움직임(그림자 추적·12fps 스톱모션·만화경 등) 결합 |
| **한글 타이포그래피, 발음 강조, UI 오버레이, 발화 싱크, 컷 전환** | **`HyperFrames` + GSAP** | 영상 AI는 한글 자소가 뭉개지고 세부 수정이 불가. 선명한 한글·정확한 타이밍은 코드가 전담 |

### 레퍼런스 직접 관찰 & 분해 (`visual-library` / `outlier-frames`)
- 연출 자료집을 먼저 열어 실제 명작 화면을 눈으로 본다(`npm run visual-summary`, `npm run visual-library -- <검색어>`). 글 설명만으로 화면을 설계하지 않는다.
- **AI 영상만 참고하면 AI 평균값에 갇힌다.** 가능한 한 실사·사람 제작 명작에서 구도·조명·컷 호흡·전환을 조각으로 뽑아 오고, 원본의 그림·문구·배치를 그대로 베끼지 않는다.
- 채택한 명작에서 **① 이미지/영상으로 뽑을 요소(질감·사물·인물)** 와 **② 코드로 움직일 요소(타이포·카메라·전환·리듬)** 를 나눈다.
- 추상어("역동적으로", "세련되게") 대신 `motion` 설계에 **구체 수치**(이징 감속, 카메라 줌/이동, 컷을 잇는 연결 요소, 스텝 프레임 12fps/30fps, 구도/전환 의도)를 적는다.
- 참고 어휘(구도·전환·색/광원·완급 반전·팔로우스로 등 94편 조사 요약): **`knowledge/ai-craft-research-2026-11-21.md`** (편마다 필요한 것만 자율 선택, 체크리스트 아님).
- 실제 사용한 레퍼런스 ID·시각과 적용 기법은 `TASKS.md`에 기록해 공개 7일 성과와 연결한다.

## 3. PHASE 10 — 무료 생성 도구 제작 도구 상자 & 후반 휴먼터치

상세 CLI 플래그·프롬프트 문법은 **`knowledge/google-ai-studio-prompting.md`** 를 참고한다.

### 1. 이미지·영상 생성 도구 상자 (`npm run image` · `npm run video`)
상황에 맞는 기법만 골라 쓴다(단순 2컷 영상에 불필요한 시트/그리드를 억지로 만들지 않는다).
- **키이미지 올인(Nano Banana 리롤 → Omni 절약)**: Omni 무료 웹은 하루 약 6회 한도가 있다. 영상에서 한도를 태우지 않고, 무료 여유가 큰 Nano Banana 단계에서 세계관·단일 광원·낮춘 채도를 잡은 **키이미지(앵커) 1장**을 충분히 뽑아 검증한 뒤 영상으로 넘긴다.
- **일관성 확보(필요 시)**: 같은 인물·핵심 소품이 여러 컷에 나올 때 `6면 시트`(정면·반측면·측면·뒷면·아래·위) 또는 `3×3 연속 스토리보드` 1장으로 구도·흐름을 먼저 검증한다.
- **2단계 참조 + 무텍스트 생성**: 장면 그림과 영상 생성(`--first` / `--last` / `--ref`)에 앵커 이미지를 연결하고, 소품·배경의 미세 텍스트·로고·스티커는 프롬프트에서 금지해 글자 뭉개짐을 막는다. 코드 레이어에 얹을 컷아웃 에셋은 가장자리가 직선으로 잘리지 않게 여백/테두리를 명시한다.
- **노드 계보 & 3대 부분 수정 & 열화 리셋**:
  - 모든 생성물 옆에는 `.prompt.json`과 버린 테이크(`assets/takes/`)를 남겨 어디서 어떤 변수 하나를 바꿔 뻗었는지 추적한다(`--parent <직전파일> --changed-var "<바꾼 변수>" --status candidate|chosen|rejected`, 조회: `node scripts/media-craft-tools.mjs lineage --dir <폴더>`).
  - 수정 시 처음부터 무작정 다시 뽑지 않고 **① 문제 프레임 캡처(`extract-frame`) → 이미지 부분 수정 → `--first` 재영상화 ② 앵글 전환 생성 → 베스트 프레임 캡처 → 재영상화 ③ 4회 이상 수정으로 열화되면 이미지를 LLM에 넣어 프롬프트로 역변환 후 처음부터 새로 생성(Fresh Generation)** 한다. 그리드/시트 분할(`split-grid`)·레퍼런스 컷(`extract-ref-clip`)도 필요 시 `scripts/media-craft-tools.mjs`로 실행한다.
- **저화질 선별 & 선택적 수용**: 핵심 동작은 `360p`로 먼저 확인하고 합격 프롬프트만 `1080p` 본생성한다. 시청자 시선이 머무는 핵심 단어·입 모양·주인공 오류는 고치되, 0.5초 스쳐 가는 배경 미세 오차에 일일 한도를 다 쓰지 않는다.
- **워터마크 4방 모서리 검수 (불변)**: `assets/` 반입 전 네 모서리를 직접 확대 확인한다. 발견 시 ffmpeg 크롭 후처리:
  `ffmpeg -i input.mp4 -vf "crop=1696:954:0:0,scale=1920:1080:flags=lanczos" -c:v libx264 -crf 18 -preset slow -an output_clean.mp4`

### 2. 후반 휴먼터치 (`HyperFrames` + `ffmpeg` + 사운드, 85점 → 완성)
AI 생성본만 이어 붙이면 85점에서 멈춘다. 마지막 디테일을 후반 레이어에서 끌어올린다.
- **HyperFrames 모션 감도**:
  - 뚝 멈추는 직선 이동 대신 감속 여운(`Easy Ease` 커스텀 이징), 덩어리 통이동 대신 요소별 시간차(Stagger)·반 박자 팔로우스로(Follow-through), 컷 사이를 잇는 연결 요소와 절제된 카메라 워킹.
  - 무맥락 장식 도형·과도한 모션 블러·불꽃/연기/스파클 파티클 남발을 피하고, 한·영 정보 위계를 분명히 나눈다.
  - 움직임 원리 참고: `npx hyperframes catalog --query "<동작>"` (무작위 값·실시간 물리 대신 시간 값 결정론적 코드로 작성).
- **8bit 톤/질감 통일 & 리듬 (`ffmpeg` · `scripts/media-craft-tools.mjs`)**: 서로 다른 AI 클립의 색온도·노출 단차를 공통 톤/미세 그레인으로 맞추고(`unify-tone`), 필요 시 BGM 비트·발화에 맞춰 클립 속도를 미세 조정한다(`detect-beats`).
- **사운드 4층 믹싱**: 나레이션(TTS) + Omni가 만든 원본 환경음(낮은 볼륨으로 유지, 불필요할 때만 `--mute`) + `npm run music`(Lyria 3.5 BGM, 더킹 + BPM 비트 맞춤) + 용도별 효과음(전환·강조·팝업 — 시청자가 놀라지 않는 낮은 볼륨 상한 준수).

### 3. 렌더 전 검수 (객관 수치 + 눈 확인)
- `npx hyperframes lint`, `npx hyperframes check`, `npm run check-terms -- videos/<프로젝트>` 통과.
- 브라우저/콘택트시트에서 직접 눈으로 확인: 정면 아이레벨·슬라이드 고착 여부, 얼굴/손/글자 열화, 컷 간 톤 단차, 글자 겹침·가림 여부. 가능하면 레퍼런스 대비 컷 밀도·화면 변화량 등 수치도 함께 대조한다(`compare-visual-metrics`).
