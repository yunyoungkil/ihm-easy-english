# MessengerFrame — EP10 쇼츠B 디자인 명세

마지막 갱신: 2026-08-25

## 컨셉

실제 메신저(카카오톡류) 대화창을 그대로 재현한다. 질문·반전·원리 설명이 전부 대화의 자연스러운 흐름처럼 읽히게 하는 것이 이 디자인의 핵심 — 별도 카드나 팝업이 아니라 "대화 안에서 답이 나온다"는 느낌을 지킨다.

쇼츠A(`ep10-shorts-a-faceless`, BlockFrame 카드)와 콜리전 파일럿(`ep10-confusion-pilot`, 다크 키네틱)과는 완전히 독립된 세 번째 시각 언어다. 팔레트·폰트·모션 어느 것도 재사용하지 않는다.

## 화면

- 1080×1920 (9:16), 세로형 쇼츠 전용.
- 안전영역: 상단·하단만 고려(상단 약 15%, 하단 약 10%). 우측 버튼 안전영역은 비우지 않는다 — 쇼츠A와 동일한 결정.
- 대화창은 화면 전체를 채운다. 상단 140px는 항상 대화 상대 헤더(흰 배경 + 이름)가 차지.

## 색상

| 토큰 | 값 | 용도 |
|---|---|---|
| `chatBg` | `#B8C9D9` | 대화창 배경 |
| `bubbleMe` | `#FFE300` | 내 말풍선(우측 정렬) — 카카오톡 옐로 |
| `bubbleFriend` | `#FFFFFF` | 친구 말풍선(좌측 정렬), 테두리 `#DDDDDD` |
| `headerBg` | `#FFFFFF` | 상단 대화 상대 헤더 |
| `ink` | `#1A1A1A` | 기본 텍스트 |
| `englishAccent` | `#FF0000` | 나레이션과 동기화되는 영어 철자 강조 (채널 공통 규칙) |
| `koreanAccent` | `#008EFF` | 나레이션과 동기화되는 한글 발음 강조 (채널 공통 규칙) |
| `bannerBg` / `bannerInk` | `#12181F` / `#FFFFFF` | 규칙 정리 배너, 브랜딩 프레임 |

노란/흰 말풍선 색은 고정이며 다른 용도로 쓰지 않는다 — "누가 말하는지"를 색으로만 즉시 구분하는 것이 이 디자인의 유일한 색상 규칙.

## 타이포그래피

- 전 요소 `CapcutKR`(`assets/fonts/capcut-korean.ttf`) 하나로 통일 — 메신저 채팅은 폰트가 여러 개 섞이면 리얼리티가 깨진다.
- 말풍선 본문: 36px / weight 500 / line-height 1.3.
- 헤더(대화 상대 이름): 34px / weight 700.
- 원리 설명 단어 표시(SOCIAL 등 영어 단어 확대): 44px / weight 800 / tracking 0.02em.
- 규칙 배너·브랜딩 칩: 44px 및 38px / weight 700~800.

## 컴포넌트

- **말풍선(bubble)**: `border-radius: 24px`, `padding: 24px 32px`, `max-width: 70~74%`. 내 말풍선은 우측 정렬 + 노란 배경, 무테두리. 친구 말풍선은 좌측 정렬 + 흰 배경 + 1px `#DDDDDD` 테두리.
- **헤더(header)**: 화면 최상단 고정 140px 바, 흰 배경 + 하단 1px 구분선 + 대화 상대 이름.
- **원리 말풍선**: 친구 말풍선과 동일한 셸 안에, 영어 단어를 확대 표시하고 규칙에 해당하는 부분만 `englishAccent`로, 한글 결과음은 `koreanAccent` 또는 화살표로 연결.
- **규칙 배너**: 대화창 위에 오버레이되는 반투명·다크 배너, 대화를 완전히 가리지 않는다(대화 상단 60~70%는 유지).
- **브랜딩 프레임**: 마지막 컷 전용. 대화창이 어두워지며 채널명 칩 + EP 번호 칩만 남는다.

## 모션 원칙

- 대화가 쌓이는 방식 그대로 모션도 "새 말풍선이 아래에서 올라와 안착"이 기본값 — 카드가 튀어 들어오는 쇼츠A/콜리전 파일럿과 의도적으로 다르게 간다.
- "입력 중..." 표시는 점 3개가 순서대로 깜빡이는 정도로만, 과장하지 않는다.
- 강조(영어 철자/한글 발음)는 나레이션이 그 부분을 말하는 순간에만 색이 들어온다 — 채널 공통 규칙(`highlightAt` 동기화) 유지.
- 규칙 배너는 슬라이드-업으로 등장, 대화창을 가리지 않을 만큼만 올라온다.
- 장면 전환은 전부 크로스페이드(0.35~0.4초) — 대화가 끊기지 않고 이어지는 느낌을 유지하기 위해 하드컷이나 슬라이드 전환을 쓰지 않는다(쇼츠A는 슬라이드였지만, 여기서는 "대화의 연속성"이 더 중요).

## 안 쓰는 것

- 카드+그림자(쇼츠A의 BlockFrame 시그니처) — 재사용 금지.
- 다크 배경 + 민트 글로우(콜리전 파일럿 시그니처) — 재사용 금지.
- 별도 팝업/카드로 규칙을 설명하는 방식 — 항상 말풍선 또는 대화창 위 오버레이로만 표현한다.
