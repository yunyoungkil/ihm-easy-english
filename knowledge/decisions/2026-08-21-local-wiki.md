# 결정: 로컬 LLM Wiki를 프로젝트 기억으로 사용

- 날짜: 2026-08-21
- 상태: 확정

## 결정

`C:\Users\yunyo\Downloads\project\knowledge`를 프로젝트의 지속형 기억으로 사용한다.

## 이유

- 긴 Notion 페이지를 반복해서 읽는 토큰 비용을 줄인다.
- 채팅 메모리 한계로 이전 결정이 누락되는 문제를 막는다.
- 시즌 쇼츠와 채널 쇼츠 C, 제작 완료와 업로드 완료 같은 상태 혼동을 줄인다.
- 실패 원인과 해결법을 다음 제작에 재사용한다.

## Notion 처리

- 현재부터 Notion을 기본 작업 기록으로 사용하지 않는다.
- 기존 Notion 전체를 이관하지 않는다.
- 로컬에 없는 필수 정보가 있을 때만 필요한 페이지를 선별해 확인한다.
- 사용자가 별도로 요청하지 않는 한 자동 업데이트하지 않는다.

## 갱신 방식

- `업무 종료` 명령을 기다리지 않는다.
- 결정이나 상태 변화가 생긴 시점에 질문이 필요한 항목만 짧게 확인한다.
- 확인된 결과를 즉시 관련 문서와 `log.md`에 반영한다.

## 안전 경계

- 구현 세부사항은 에이전트가 기록한다.
- 전략·일정·완료 판정·비용 발생은 사용자가 결정한다.
- 모순은 자동으로 덮어쓰지 않고 사용자에게 보고한다.
