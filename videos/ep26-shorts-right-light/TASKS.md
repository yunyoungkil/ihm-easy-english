# TASKS — ep26-shorts-right-light

- 재료: 사용자가 만든 나레이션 1개(35.8초)를 10줄로 잘랐다. 경계는 쉼(-38dB 0.25초)으로 찾고 조각마다 whisper로 대본과 대조했다. whisper가 5번째 줄 "리을"을 두 번 다 "리얼"로 적어서 사용자에게 들어 봐 달라고 했고, "리을로 들린다"는 답을 받았다. 원어민 문장 `dial_01_right_light`, 단어 right·light(남성)는 롱폼에서 복사. `scripts/prepare-assets.mjs`.
- 원어민 문장 안 단어 시각: 롱폼의 `dial_01_right_light.words.json`은 light가 3.0초에 끝나 파일 길이(2.449초)보다 길다. 다른 파일 기준 값이라 쓰지 않고 50ms 소리 크기로 다시 쟀다(right 0.62초, light 1.84초).
