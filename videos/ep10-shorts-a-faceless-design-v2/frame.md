# EP10 Shorts A — Editorial Brutalist V2

The supplied FRAME is used as the structural reference: hard rectangular splits, warm paper, black fields, condensed display type, square geometry, asymmetrical editorial spacing, and restrained red voltage.

Channel learning semantics override the source palette when instructional meaning is present. English target letters use learning red, Korean sounds use learning blue, and only complete English target words may use the yellow slab.

## Rules

- One dominant focal element per frame.
- Pair that focal element with no more than one supporting message.
- No rounded cards, gradients, glow, blur, or soft shadow.
- Use hard panels, crops, hairlines, large type, and editorial whitespace.
- Do not use decorative page numbers, vertical labels, redundant English chrome, or repeated explanations.
- Korean carries equal visual authority; it is never a small translation caption.
- Keep load-bearing copy inside 80–250px vertical safe margins.
- This V2 is a static design comparison only. Motion remains intentionally empty.
