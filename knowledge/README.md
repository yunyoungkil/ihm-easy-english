# 프로젝트 지식 위키

이 폴더는 「이해하면 쉬운 영어」 채널을 장기간 운영하기 위한 지속형 기억이다.

## 역할 분리

- `data/youtube/`: API가 수집한 원본 데이터. 수정하지 않는다.
- `scripts/`, `src/`, `public/`: 실제 제작 자산과 코드.
- `knowledge/`: 현재 상태, 운영 판단, 제작 교훈과 변경 이력.
- `raw/`: 변경하지 않는 외부 원본 자료.
- Notion: 기본적으로 사용하지 않는다. 로컬에 없는 필수 정보가 있을 때만 필요한 문서를 선별해 읽는다.

## 기록 원칙

- 사실과 판단을 구분한다.
- YouTube 수치는 원본 JSON 경로와 동기화 날짜를 함께 쓴다.
- 완료는 실제 검수 또는 사용자 승인이 끝났을 때만 표시한다.
- 기존 결정을 바꾸면 과거 기록을 지우지 않고 `decisions/`에 변경 근거를 남긴다.
- 전략·일정·완료 판정은 사용자 확인 후 확정한다.
- 프레임 조정, 캐시 문제, 코드 수정 같은 구현 세부사항은 작업 중 바로 기록한다.
- `업무 종료`라는 별도 명령을 기다리지 않는다.

## 작업 시작 순서

1. `index.md`
2. `now.md`
3. 오늘 작업과 직접 관련된 문서 1~2개
4. 필요한 경우에만 이번 달 `logs/YYYY-MM.md`의 최근 항목

`current-status.md`와 기존 `log.md`는 이전 기록 확인이 필요할 때만 읽는다.

## 기록 위치

- 현재 업무: `now.md`
- 에피소드별 상태와 결정: `episodes/`
- 안정된 제작·운영 원칙: 기존 주제 문서 또는 `rules/`
- 날짜별 작업 이력: `logs/YYYY-MM.md`
- 전략을 바꾸는 결정: `decisions/`
- 원본 수치: `data/`
- 외부 참고 원본: `raw/`

## 점검

`npm run wiki:lint`로 깨진 링크, 고립 문서, 비대해진 `now.md`를 확인한다.

## 질문이 필요한 시점

- 콘텐츠 방향 또는 타깃 시청자가 바뀔 때
- 제작 완료·검수 완료·업로드 완료를 확정할 때
- 업로드 날짜와 공개 순서를 정할 때
- 비용이 발생하거나 기존 전략을 뒤집을 때

질문은 한 번에 필요한 것만 짧게 한다.
