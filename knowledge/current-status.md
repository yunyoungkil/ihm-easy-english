## 제목·썸네일 패키징 분석 기능

- 롱폼의 제목+썸네일 조합과 영상 API 성과를 한 화면에서 비교한다.
- EP9 V2를 첫 패키징 기준점으로 등록했다.
- 노출수·CTR은 썸네일 전용 값이 아니라 영상 도달 성과로 24시간·48시간·7일·28일 시점별 한 번만 저장한다.
- 각 측정값에는 당시 적용된 패키징 ID를 연결한다.
- API에서 가져온 기존 롱폼 제목과 썸네일도 분석 화면에 자동 표시한다.
- YouTube Studio 고급 모드 CSV를 업로드하면 영상 ID 또는 제목으로 연결해 노출수·CTR을 일괄 저장한다. 한국어·영어 열 이름을 자동 인식하며 직접 입력은 개별 보정용으로만 남긴다.
- 운영 방식은 매월 1회로 확정했다. `imports/youtube-studio`에 Studio 내보내기 폴더를 넣으면 대시보드가 폴더명 기간과 제목, `표 데이터.csv`를 자동 분석한다.
- Studio 노출수·CTR은 공개 후 30일이 지난 영상만 수집한다. EP8은 2026-09-09부터 수집 대상이며, 기존 조기 데이터는 보존하되 분석 화면에서 제외한다.
