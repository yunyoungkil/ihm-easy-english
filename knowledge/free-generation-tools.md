# 무료 생성 도구: 워터마크와 우선순위

`AGENTS.md` "이미지 생성 2단계 원칙"에서 옮겨 온 표와 시험 결과다(2026-11-13, 원문 그대로). 새 도구는 처음 쓸 때 워터마크 유무를 확인해 이 표에 날짜와 함께 적는다.

- **무료 생성 도구와 워터마크 (2026-11-11 사용자 알림, 같은 `Gemini-Automation` 크롬 프로필로 자동화)**:
| 도구 | 쓸 곳 | 워터마크 | 우선순위 |
|---|---|---|---|

| gemini.google.com (지금의 `generate-web-gemini-image.mjs`) | 이미지·영상 | **첫 장 이후 찍힘**(2026-11-11 EP24 두 번째 쇼츠에서 세 번째 그림인 썸네일 오른쪽 아래에 별 로고로 실제 확인) | AI Studio 자동화가 준비되기 전까지만 |
| AI Studio의 **Omni 1.2 Flash** | 영상(배경·짧은 장면) | **눈에 보이는 워터마크 없음 — 확인됨 (2026-11-12)** (EP24 두 번째 쇼츠 1번 장면 `720×1280` 9:16 5초 클립 네 모서리 확대 확인, 비가시 SynthID는 별도. 비율 `Auto`/`16:9`/`9:16`만 지원, 3~15초·24fps, 해상도 `360p`/`720p`/`1080p`/`4k` 선택(스크립트 `--resolution`, 기본 720p). 소리(대사·입 모양 포함)를 함께 만든다: 배경 클립은 `-an`으로 지우고(기본값), 사람이 말하는 장면은 `--keep-audio`로 살린다. 2026-11-21 웹·유튜브 확인: 정지 그림을 먼저 만들어 `--image`로 붙이고 대사는 인물별로 줄을 나눠 따옴표로 적으면 목소리가 안 뒤바뀐다, 두 사람 대화는 15초보다 6~10초 클립을 이어 붙이는 편이 박자가 낫다, 우리 음성 파일을 넣어 입을 맞추는 기능은 API에서 막혀 있다, 한국어 대사: 공식 자료는 없지만 2026-11-21 시험에서 됨 — AI Studio 정지 그림(`npm run image`, 9:16) → `--image`·`--resolution 1080p`·`--duration 6`·`--keep-audio`로 실제 1080×1920 24fps·소리 포함 클립, 대사 "이 버튼, 영어로 읽으면 '버튼'이 아니에요."를 whisper가 그대로 받아씀, 말하는 0.15~3.98초 동안 입이 움직이고 끝나면 다문 미소, 얼굴 변형 없음. 사용자가 직접 들어 보고 "자연스럽고 입 모양도 맞다" 확인(2026-11-21)) | 영상 1순위, 자동화 `npm run video`(`scripts/generate-aistudio-video.mjs`, 2026-11-21 실제 생성 확인) (`flow.google.com`은 `PRO` 계정에서도 "거주 중인 지역에서는 워터마크 표시가 필수입니다" 확인되어 후순위) |
| **제미나이 앱**(gemini.google.com)의 영상 | 영상 | 워터마크가 찍힘 → **크롭으로 가린다**(2026-11-12 사용자 안내) | 영상 2순위. 워터마크 모서리가 화면 밖으로 나가게 자르고 원래 크기로 키운 뒤 네 모서리를 확대해 잔상 확인. 잘려도 되는 여백이 있는 장면에만 쓴다(키운 만큼 화질·가장자리 구도 손실). 소리가 같이 생성되므로 `muted`/`-an` 필수 |
| AI Studio의 **Lyria 3.5** (`new_music?model=lyria-3.5`) | 배경음악(BGM) | **오디오 워터마크 없음 — 확인됨 (2026-11-12)** (`44.1kHz` 스테레오 `192 kbps` MP3, `0~33초` 평균 `-14.1 dB`. ID3의 C2PA 메타데이터는 `ffmpeg -map_metadata -1`로 정리. API 키 미선택 웹 세션 무료) | **음악·배경음 1순위** (`Composer` 모드 + 긍정문만 작성해야 후반 허밍 유입 방지). 자동화 `npm run music`(`scripts/generate-aistudio-music.mjs`, 2026-11-21 실제 생성 확인, 결과는 약 62초라 필요하면 자른다) |
| **flowmusic.app** | 배경음악(보조)·효과음·음악 비디오 | **오디오 워터마크 없음 — 확인됨 (2026-11-12)** (`Clear Speech Study Beat.mp3` `48kHz` 스테레오 `167.4초`, `... → Download → MP3`. 영상 다운로드는 미시험) | 음악 2순위 · 효과음/커뮤니티 프롬프트 참고용 (AI Studio `Lyria 3.5`는 크레딧 소모 없음) || AI Studio의 **Gemini 3.8 Flash TTS** (`generate-speech` 화면, `Gero` 목소리) | 나레이션(음성) | **눈에 보이는·들리는 표시 없음 — 확인됨 (2026-11-16)** (화면 방식으로 만든 EP30 14줄 모두 24kHz 16bit 모노 WAV, RIFF+`fmt `+`data` 덩어리뿐이라 C2PA 덩어리도 없음. 앞 첫 샘플 전부 0, 끝 0.1초 최대 진폭 124(32768 기준) 이하, 클릭 없음. API(무료 키)는 하루 10회 안에서의 보조(아래 절) |
  - AI Studio(`Omni 1.2 Flash`, `Lyria 3.5`)는 API 키 미선택 웹 플레이그라운드에서 무료(사용자 알림, `Lyria 3.5`는 무료 `192 kbps` MP3 출력 확인). **flowmusic은 무료 크레딧 안에서만 무료**(2026-11-12 사용자 정정) — 왼쪽 아래 `💎 2`는 크레딧이 아니라 데뷔 활동 점수(`2/1000`)이고, **실제 남은 크레딧은 왼쪽 아래 계정 설정 메뉴(`Settings menu`/`설정 메뉴`) 안 `... credits`**에서 확인한다(2026-11-12 시험 계정 `AmbientNovel PLUS`에서 `10575 credits` 확인, `/pricing` 기준 Free는 일일 충전 + 동시 2개, 유료 Starter/Plus/Member 기준 곡당 약 5크레딧). 크레딧을 다 쓰면 다음 날로 넘기고, 유료 결제로 넘어가지 않는다. 프롬프트를 쓰기 전에 flowmusic 커뮤니티 피드의 인기 음악·음악 비디오와 그 프롬프트를 참고한다(사용자 제안). 처음 쓸 때 실제로 워터마크가 없는지, 무료가 맞는지 확인해 이 표에 "확인됨"과 날짜를 적는다.
  - **Omni 1.2 Flash 무료 웹 화면에도 하루 한도가 있다**(2026-11-21 확인): 이 PC에서 성공 6번(다른 PC가 같은 날 쓴 것 포함 여부 모름) 뒤 `Quota exceeded: you have reached the daily limit of requests for this model (resets in 17시간…)`. 그 전에 짧은 간격으로 연달아 부를 때도 한 번 막혔다가 바로 다음 호출은 됐다. 같은 날 Nano Banana 2.1 그림은 11장을 만들어도 막히지 않았다 → 많이 뽑고 고르기는 그림에서 하고, 영상은 고른 장면만 뽑는다(조사의 "정지 그림이 좋으면 영상은 따라온다"와 같은 순서). 웹 확인(2026-11-22): AI Studio 무료 화면의 Omni 하루 개수는 공식 숫자가 없다. Google Flow는 무료 하루 50크레딧(360p 4초 4크레딧~10초 7크레딧, [Flow 도움말](https://support.google.com/flow/answer/16526234))이지만 Flow는 워터마크가 찍힌다. 개발자 포럼에는 미리보기 모델 하루 약 20번에서 막혔다는 글이 있다([Google AI 포럼](https://discuss.ai.google.dev/t/quota-allowlist-increase-request-gemini-omni-flash-preview-video-generation/175891)). 실제로 잰 숫자는 위의 성공 6번뿐이다.
  - gemini.google.com으로 만든 그림은 반입 전에 반드시 네 모서리, 특히 오른쪽 아래를 확대해 별 로고를 찾는다. 있으면 아래 "AI 생성 미디어 워터마크" 절대로 크롭하거나, 비워 두는 빈 여백이면 같은 여백 조각으로 덮는다.
  - 배경음악을 편마다 새로 만들 수 있게 됐으므로 같은 `track.mp3`를 모든 쇼츠에 돌려 쓰지 않는다 — "같은 틀의 영상을 찍어 내지 않는다" 규칙과 같은 이유.

## API 키(무료 `GEMINI_API_KEY`)로 가능한지 (2026-11-16 조사, 호출은 모델 목록 읽기 한 번과 음성 시험뿐)

- **음성(TTS)**: 가능하지만 **`gemini-3.8-flash-tts` 무료 하루 10회**다. 2026-11-16 429 응답 본문 원문: `{"error":{"message":"Rate limit exceeded for model gemini-3.8-flash-tts (limit: 10 requests per day on Free Tier). Please retry in 16h33m12s or upgrade your tier at https://ai.dev/rate-limit.","code":"too_many_requests"}}`(`details`·`quotaId` 없음). 2026-11-15 15:26 UTC 기준 16시간 33분 뒤 = 약 2026-11-16 08:00 UTC = **17:00 KST에 풀린다**(태평양 자정 기준으로 보이나 추정). 한 편 14줄은 하루에 못 만들어 보조로만 쓴다. 지시(톤)는 대본에 섞지 말고 `POST /v1beta/interactions`의 `annotations[{type:"speech_metadata", style}]`로 보낸다(공식 `aistudio.google.com/docs/speech-generation`, 이 방식으로 n02 한 줄 시험 시 영어 지시문이 소리로 읽히지 않음). 다른 TTS 모델(`gemini-3.8-flash-lite-tts`, `gemini-3.1-flash-tts-preview`)이 목록에 있으나 한도가 모델별인지·목소리가 같은지는 확인하지 못했다.
- **음악**: 모델 목록에 `lyria-3.5`, `lyria-3-pro-preview`, `lyria-3-clip-preview`(30초), `lyria-realtime-exp`가 있다. **가격 페이지(`aistudio.google.com/docs/pricing`)에 Lyria 3.5 "Free tier: Not available", 곡당 0.08달러, Clip 0.04달러**라서 API 키로는 만들지 않고 **AI Studio 화면(`new_music?model=lyria-3.5`, 2026-11-12 워터마크 없음 확인)이 기본**이다. API 출력은 MP3(3.5는 WAV도 가능) 44.1kHz 스테레오에 사람 귀에 안 들리는 SynthID 워터마크 포함이라고 문서에 있다. 호출은 하지 않아 실제 응답은 확인하지 못했다.
- **효과음**: 효과음 전용 생성 모델이나 문서를 찾지 못했다. 확인하지 못했다.
