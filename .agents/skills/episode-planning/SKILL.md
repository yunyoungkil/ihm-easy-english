# 에피소드 기획 마스터 워크플로우 (11-Phase Orchestrator)

이 스킬은 채널 기획부터 에셋 프롬프트 및 사후 성과 리뷰까지의 전체 기획 프로세스를 총괄합니다.
기술적 제작(TTS 생성, whisper 추출, HyperFrames 구현, 렌더링)은 `knowledge/VIDEO_WORKFLOW.md`와 `hyperframes` 스킬로 연계됩니다.

---

## 🚨 최우선 절대 원칙: ❌ 절대 금지 ➔ ⭕ 대체 표준 규격

> **어떤 단계의 작업을 수행하든 아래 규칙을 위반하는 것은 엄격히 금지됩니다.**

| 영역 | ❌ 절대 금지 (적발 시 즉시 반려) | ⭕ 대체 표준 규격 (철저 준수) |
|---|---|---|
| **대외 용어 전반** | `[듣기 드릴]`, `드릴(drill)`, `미니멀 페어`, `파열음`, `조음`, `유성음`, `무성음`, `긴장모음`, `TENSE/LAX` | `[반복 듣기]`, `[집중 듣기]`, `[소리 연습]`, `[귀 훈련]`, `짝단어` |
| **같은 틀 반복** | 직전 편의 구성·제목 틀에 단어만 교체, 듣기 영상 3편 연속 | **이 영상에만 있는 코너 1개 이상**, 목차와 제목 시안을 직전 영상들과 **비교표로 보고한 뒤** 다음 단계 진행 (2026-11-06, EP24~29는 소급 안 함) |
| **타겟 및 화법** | 해외 유학/거주 경험, 해외 카페 주문 실패 등 가짜 일화 날조 | **국내 거주 3060 보통 성인** (학창시절 표기 괴리, 미드/유튜브 장벽, 외래어 배신감) |
| **썸네일 텍스트** | 6단어 이상 장문, 제목 그대로 복사, 채널명 배지 | **5단어 이하** 엄격 제한 (헤드라인+카피 합), 칩은 2단어 이하 (`[반복 듣기]`) |
| **대본 시작 어휘** | `솔직히` 상투적 반복, 영단어로 문장 시작 (`Coffee나...`) | 순수 한국어로 자연스러운 시작 (`학창 시절에...`, `우리가 흔히...`, `영어 단어를 보면...`) |
| **목적격 조사** | `귀 뚫어 드립니다`, `소리 뚫어 드리겠습니다` | **`귀를 뚫어 드리겠습니다`**, **`소리를 뚫어 드리겠습니다`** (`을/를` 필수) |
| **단어 음절 표기** | 한글 발음 억지 쪼개기 (`[쉬 · 입]`, `[푸 · 울]`, `[롸 · 이트]`) | 영어 2음절 이상 철자에 가운뎃점(`cof · fee [커피]`), 1음절은 `[쉽]`, `[풀]` 유지 |
| **접미사/음소 강조**| 단어 전체를 단색으로 칠해 타겟 발음(-ed, -s 등)이 묻힘 | **어간 뉴트럴 블랙 (`#111111`) + 타겟 접미사/음소만 고대비 강조 컬러 분리** |
| **UI 메타 문구** | 화면 카드에 "남·여 교차 6회 반복", "TTS 3회" 라벨 노출 | **사족 문구 완전 제거, 오직 시각적 인디케이터 점(dots)·진행 바로만 표현** |
| **UI 줄바꿈 방지** | 알약 뱃지, 카드 단어가 좁아서 2줄로 찌그러짐 | **핵심 텍스트에 `white-space: nowrap;` 강제 및 사전 반응형 폰트 크기 계산** |
| **미디어 워터마크** | 제미나이 별 로고, 런웨이 로고가 화면에 1픽셀이라도 노출 | **프롬프트 네거티브 강제 + 반입 전 4방 모서리 시각 검수 + ffmpeg 크롭 후처리** |
| **에셋 생성 필터** | 텍스트 카드, 뱃지, CSS 도형, 모션을 이미지/영상으로 생성 | **HyperFrames 골든룰: HTML/CSS/GSAP 구현 가능한 것은 프롬프트 생성 금지** |

## 🛑 단계별 진행 및 승인 게이트 원칙

1. **절대적 승인 게이트 (Approval Gate)**:
   - 각 Phase가 완료되면 반드시 작업을 멈추고 산출물을 사용자에게 명확히 보고합니다.
   - 사용자가 "계속", "다음", 또는 피드백을 주기 전까지 다음 Phase로 절대 임의 진행하지 않습니다.
2. **사전 파일 존재 확인 의무화**:
   - `REVIEW.md`, `thumbnail-prompts.md`, `SCRIPT.md`, `visual-prompts.md` 등을 작성할 때 "내가 새로 만든다"고 가정하지 않고, 반드시 먼저 `view_file`로 기존 파일이 있는지 확인 후 갱신합니다.
3. **영상 렌더링 임의 실행 금지**:
   - 컴포지션 구현 완료 후 린터 검증을 통과했더라도 에이전트 임의로 렌더링 명령어를 실행하지 않으며, 사용자의 명시적 승인 후 착수합니다.
   - 승인을 요청하기 전에 `npm run check-terms -- videos/<프로젝트>`로 금지어를 검사해 결과를 함께 보고합니다. 렌더 명령은 훅이 같은 검사로 막습니다.
