# 결정: 대표님 1:1 발음 과외방(개인 학습) + 말하기 결 카드 (2026-11-26)

- **상태**: 확정 (2026-11-26 사용자 승인: 논의 합의 후 “해봐”)
- **맥락**: 채널을 만든 본래 이유 중 하나가 대표님 본인이 영어를 발음부터 배우는 왕초보(기초 단어 읽기 수준)로서 기획·제작 과정에서 직접 배우기 위함이다. 동시에 AI 대본의 평균값을 넘어 ‘대표님을 입히는 마지막 퍼즐’을 고민하며 논의했다.

## 1. 조사 근거 (확인한 사실 + 반대 근거)

1. **비교 시트 실측 (`scripts/transform-sheet.mjs`, `outlier-report-view.mjs`)**:
   - 기존 비교 시트의 `전체 대본 보기`는 각 컷의 한국어 나레이션(`narration`)만 이어 붙여, 실제 영상에 들어가는 원어민 영어 음성(`voiceEn`)이 빠져 있어 시청자 귀의 순서대로 읽기 어려웠다.
   - 경쟁 아웃라이어 리포트 66편 중 43편에서 시청자 미해결 질문 53건이 이미 수집되어 있어, 편별 ‘시청자 질문 10가지’를 실제 시청자 궁금증과 대본에서 뽑아낼 기반이 있다.
2. **성인 왕초보 발음·학습 연구 (찬성 + 반대 근거)**:
   - **소리 구분 훈련(HVPT)·알아차림 가설**: 귀로 차이를 먼저 알아차리게 하는 훈련이 성인 발음·듣기에 큰 효과($g \approx 0.67\text{–}0.92$). 단, 한글 표기만 눈으로 보면 한글 발음이 굳어지는(화석화) 함정이 있어 **바로 듣는 영어 소리 버튼**이 필요하다.
   - **소리 내어 말하기 효과(Production Effect, MacLeod 등 2010 · Fawcett 2013)**: 눈으로 읽는 것보다 핵심 단어 3~5개만 입으로 한 번 말해 볼 때 기억·발음 유지력이 뚜렷하게 올라간다. 단, 무작정 빠른 쉐도잉은 오개념을 굳히므로 **입·혀 한 줄 감각**을 먼저 본다.
   - **과외식 안내 + 편하게 추측 후 즉시 교정 (Koh 등 2018 · 53편 메타분석)**: 정답을 보며 옮겨 적으면 공부가 안 되고, 반대로 진짜 왕초보에게 가이드 없이 빈칸을 채우게 하면 좌절감과 포기가 온다. 따라서 **AI가 1:1 개인 선생님, 대표님은 1번 학생**으로서 ‘나도 궁금해’ 체크나 짧은 추측만 해도 선생님이 바로 쉽게 설명해 주는 구조가 맞다.
   - **간격 반복(Spaced Retrieval)**: 단발성 학습은 금방 잊히므로, 다음 편 비교 시트를 열 때 지난 편에서 ‘아직 헷갈려요’를 누른 1~2개만 가볍게 복습 카드로 띄운다.
3. **채팅 기록 기반 말하기 결 추출 (구글 드라이브 95개 대화 실측 + 문체 전이 연구)**:
   - 실제 보관함 최근 12~40개 대화 확인 결과 절반 이상이 작업 지시·확인·타 프로젝트·붙여넣기다. 원문을 그대로 넣으면 매체 불일치·과장 흉내(만화 캐릭터화)·사적 내용 혼입 위험이 크다.
   - 따라서 원문은 버리고 대표님의 **생각하는 결·호흡(담백함·현실 감각·수평적 시선·짧은 확인 질문)**만 1장짜리 카드(`knowledge/creator-voice-card.md`)로 압축해 대표님 확인을 거쳐 참고한다.

## 2. 확정 경계 (기존 워크플로우와 철저히 분리)

1. **기존 제작·성장 워크플로우는 건드리지 않는다**:
   - 비교 시트 승인 관문(Gate 1), 안전 검사, 제작·예약·7일 성과 정산 흐름에 **의무나 차단 조건을 단 하나도 추가하지 않는다.**
   - 1:1 발음 과외방은 **오직 대표님 개인 학습 공간**이며 바쁜 날 건너뛰어도 제작에 영향이 없다.
   - 데이터도 시트 원본을 오염시키지 않고 `data/youtube/creator-study/<sheetId>.json`에 별도 저장한다.
2. **대본에 나를 녹이는 방식은 채널 제1 슬로건 그대로**:
   - 학습 기록과 말하기 결 카드를 **매 편 기계적으로 다 넣지 않는다**(방법 비고정·탈템플릿).
   - 대표님이 1번 학생으로 배우며 남긴 막힘·체감·궁금증·수정한 문장 중 **이번 영상의 완성도와 3060 시청자 이해·재미를 높이는 알짜만** 선별해 이번 대본·고정 댓글·다음 편 소재(`next-episode-input.md`)에 자연스럽게 녹이고, 공개 뒤 7일 실제 결과로 배운다.

## 3. 구현 구성

1. **비교 시트 안 ‘1:1 발음 과외방’ (`scripts/creator-study.mjs`, `outlier-report-view.mjs`, `youtube-analytics-server.mjs`)**:
   - 시작 30초 지난 편 복습(최대 2개) → 1단 시청자 순서 노션 느낌 대본 편집기(영어 소리 칩 즉시 재생 + 마우스 강조 + 문장 수정/질문) → 2단 핵심 단어 3~5개 1:1 입모양 과외 + 내가 막힌 질문칸 → 3단 시청자 질문 10가지(선생님 설명 기본 숨김 + ‘나도 궁금해’ + 편하게 추측 적기).
   - `draft` 시트에서 대표님이 직접 고친 문장은 원할 때만 버튼 한 번으로 컷 대본에 반영 가능(되돌리기·기존 안전 검사 유지).
2. **대표님 말하기 결 카드 (`knowledge/creator-voice-card.md`)**: 대본 작성·AI 티 제거 시 은은한 조미료로 참고.
3. **다음 기획 입력 연결 (`scripts/next-episode-input.mjs`)**: 대표님이 ‘나도 궁금해’·‘아직 헷갈려요’·‘질문’으로 남긴 항목 중 최근 미해결 재료를 비차단 참고 절로 자동 요약.

## 4. 검증할 가설

- 3~5편 운영 뒤 ① 대표님이 실제로 매 편 5분 안쪽으로 부담 없이 쓰는지(지속률) ② 대표님 반응·결이 녹아든 편이 이전 편보다 시청 지속률·댓글 반응에서 나아지는지 실측해 다듬는다.
