# EP8 Softboard Test — Design Spec

## Source and purpose

`../../raw/Images/frame-md-soft-neumorphic-ui-board-showcase-frame-pack/FRAME.md`의 차분한 소프트 뉴모피즘 문법을 EP8의 설명 장면에 맞게 재해석한다. 이것은 채널 전체 리브랜딩이 아닌 16:9 설명 구간 테스트다.

## Palette

- Background: `#D8D7D3`, `#C9C7C2`, `#BEBBB5`
- Surface: `#E7E4DE`
- Ink: `#555751`
- Accessibility ink: `#30332F`, `#37474D`, `#416A58`
- Support: `#789094`, `#7F9E8F`, `#B6ACC9`
- Soft white: `#F3F2ED`
- Small marker only: `#D45662`

## Type

- Korean: `StudyKorean`, weight 400–600
- Latin: `StudyLatin`, weight 400–600
- 큰 여백과 짧은 문장을 우선한다. 검은 외곽선·과한 굵기·전부 대문자 장식은 쓰지 않는다.

## Shapes and depth

- 큰 라운드 카드와 원형 버튼을 사용한다.
- 표면보다 어두운 넓고 부드러운 그림자와 반대 방향의 옅은 하이라이트를 함께 사용한다.
- 색은 정보 구분용으로만 쓴다. 강한 네온·검은 테두리·유리 질감은 금지한다.

## Motion

- 0.4–0.7초 `power3.out`의 조용한 등장.
- 장면 사이에는 0.5초 크로스페이드만 사용한다.
- 버튼의 촉각 반응은 한 번, 작게 사용한다. 무한 루프와 바운스는 사용하지 않는다.
