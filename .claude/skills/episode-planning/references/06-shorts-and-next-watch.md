# Phase 12: 쇼츠 파생과 다음 영상 연결

롱폼 한 편을 만들면 거기서 끝내지 않는다. 쇼츠로 새 시청자를 데려오고, 롱폼끼리 이어 보게 만들어 구독으로 연결한다.

**왜 필요한가 (2026-11-06 점검)**: 최근 90일 조회수의 96%가 쇼츠에서 나왔는데, 9월 2일 이후 쇼츠 공개는 0개다(`knowledge/now.md`). 채널 전략도 "쇼츠는 신규 도달과 구독 획득, 롱폼은 신뢰와 시청 시간"으로 역할을 나눈다(`knowledge/channel-strategy.md` 성장 구조). 롱폼만 내면 새 시청자가 들어올 길이 거의 없다.

**언제 하나**: 롱폼 대본(Phase 8)이 확정된 뒤, 제작 단계에서 롱폼과 함께 계획한다. 쇼츠 기획은 Phase 5에서 "세트"로 정했으면 그 설계를 따른다.

## 1. 쇼츠 파생 (롱폼 1편당 2개 기본)

`knowledge/content-formats.md`의 쇼츠 형식을 쓴다.

| 형식 | 구조 | 이 롱폼에서 고를 장면 |
|---|---|---|
| Track A 퀴즈형 | 발음 판별 → 생각 시간 → 정답 → 최소 원리 → 롱폼 연결 | 롱폼의 퀴즈·짝단어 비교 구간 |
| Track B 반전·발견형 | 익숙한 단어의 예상 밖 발음 → 원리 발견 | 롱폼 훅(F01)이나 "반전 꿀팁" 구간 |
| 채널 쇼츠 C | 롱폼과 독립된 확장형 | 여러 편에 걸친 공통 원리 |

1. 롱폼 `SCRIPT.md`에서 쇼츠로 뺄 장면 2개를 고르고, 각각 어느 형식인지 정한다. A와 B는 같은 화면을 복제하지 않는다(`content-formats.md` Track B 규칙).
2. **첫 1초 훅**을 장면마다 한 줄로 적는다. 쇼츠는 첫 화면에서 넘겨지면 끝이다.
3. **제목 비교**: 최근 쇼츠 5개 제목과 나란히 보여 주고, 앞부분이 같은 틀이면 다시 쓴다(`CLAUDE.md` "같은 틀의 영상을 찍어 내지 않는다" 3번).
4. 화면 규칙은 `knowledge/production-rules.md` "쇼츠 화면" 절, 금지어는 SKILL.md 상단 표를 따른다.
5. 산출물: `videos/<프로젝트>/SHORTS.md`(장면, 형식, 훅, 제목 시안, 연결할 롱폼).

## 2. 롱폼으로 연결하기

쇼츠를 본 사람이 롱폼으로 넘어와야 시청 시간과 구독이 쌓인다.

- 쇼츠의 **설명란 첫 줄과 고정 댓글**에 관련 롱폼 링크를 넣는다.
- 쇼츠 마지막 장면에서 롱폼을 **제목이나 내용으로** 가리킨다("-ED 소리 3가지 전체 영상"). 화면에 `EP28` 같은 내부 번호를 쓰지 않는다(`production-rules.md` 공개 일정 절).
- 롱폼이 아직 공개 전이면, 링크 칸을 비워 두고 체크리스트에 "롱폼 공개 후 링크 넣기"를 적는다. 자리표시자 링크를 넣은 채 올리지 않는다(업로드 전 금지어·빈 링크 검사가 막는다).

## 3. 다음에 볼 영상 설계 (구독 전환)

구독은 보통 한 편을 보고 다음 편으로 이어서 볼 때 생긴다. 소재 단계(Phase 4~5)에서 이 편이 어디로 이어질지 미리 정한다.

1. **엔드스크린 연결**: 기존 규칙대로 **직전 편**을 건다(`production-rules.md` "엔딩 화면 연결 영상은 항상 직전 편"). 여기에 같은 주제 묶음의 다른 편이 있으면 두 번째 칸 후보로 적는다.
2. **재생목록**: 이 편이 들어갈 재생목록을 정한다(예: "짝단어 소리 구분", "끝소리 규칙"). 맞는 재생목록이 없으면 새로 만들지 제안한다.
3. **주제 묶음**: 비슷한 소재 2~3편을 묶음으로 보이게 하되, 같은 틀 반복 규칙은 그대로 지킨다. 묶음은 "주제가 이어진다"는 뜻이지 "구성이 같다"는 뜻이 아니다.
4. 끝 화면, 재생목록, 댓글 고정은 자동 업로드 범위가 아니므로 업로드 체크리스트에 사용자가 스튜디오에서 할 일로 적는다(`CLAUDE.md` Client Script Integrity 5번).

산출물: `BRIEF.md`에 "연결" 칸(엔드스크린 2칸, 재생목록, 묶음 이름)을 적는다.

**멈춤 지점**: 없음. 쇼츠 제작 착수와 렌더는 롱폼과 같은 렌더 승인 게이트를 따른다.
