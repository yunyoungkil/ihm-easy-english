# 콘텐츠 포맷

## 시즌 롱폼

- 한 편에서 하나의 영어 발음·듣기 원리를 설명한다.
- 단순 암기가 아니라 “왜 그렇게 들리는가”를 왕초보가 이해하게 한다.
- 시즌1은 EP1~EP10이며 롱폼 제작은 완료됐다.
- 시즌2는 문장 속 연결·축약·리듬을 다루기로 정했으나 **아직 시작 안 함** — EP11(GONNA)·EP12(Want
  vs Won't)은 시즌2가 아니라 **단편**이다(아이디어 보드가 시즌 주제와 무관하게 시청자 고통점·
  시장수요·채널 적합도 점수만으로 소재를 고르기 때문). 상세:
  [단편/시즌 분류 정리 결정](decisions/2026-09-03-standalone-vs-season-episodes.md).
- **단편**: 아이디어 보드(데이터 기반)로 고른 독립 에피소드. 시즌 연결성 없이 성장·인기가 목적.
  EP 번호는 제작 순서 참고용일 뿐 시즌 소속을 뜻하지 않는다.

## 시즌 Track A

- 퀴즈형 쇼츠.
- 발음 판별 → 생각 시간 → 정답 → 최소 원리 → 관련 롱폼 연결.
- 대략 45~55초를 기준으로 하되 실제 TTS 길이를 우선한다.

## 시즌 Track B

- 반전·발견형 쇼츠.
- 익숙한 단어의 변화나 예상과 다른 발음을 이용해 원리를 발견하게 한다.
- Track A와 같은 화면을 복제하지 않고 모션 방향과 정보 순서를 달리한다.
- **Track B끼리도 디자인을 재사용하지 않는다.** 매 에피소드 새 컨셉(EP10: 카톡 메신저 UI 등)으로
  만든다 — 2026-08-25 사용자 확정. 고정 템플릿화보다 신선함을 우선.

## 채널 쇼츠 C

- 특정 시즌 한 편의 부속물이 아니다.
- 채널 전체 롱폼 소재에서 독립적으로 뽑는 확장형 쇼츠다.
- 신규 시청자 도달과 기존 롱폼 재활용이 목적이다.
- 첫 실험인 슈와 쇼츠는 2026-08-21 기준 평균 시청률 71.49%, 구독자 +5다.

## 공개 기본 순서

- 시즌 한 편: 롱폼 → Track A → Track B.
- 채널 쇼츠 C는 시즌 공개 흐름과 별도의 슬롯으로 운영한다.
- 실제 날짜는 최신 업로드 공백과 성과를 확인한 뒤 사용자와 확정한다.
