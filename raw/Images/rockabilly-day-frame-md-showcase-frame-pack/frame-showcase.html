Principles

Do / Don't · at frame scale

Do

  • Compose centered by default; break to left only for the band ledger.
  • Vary the composition axis every 1–2 frames.
  • Let one red silhouette carry the frame — misreg offset is ambient.
  • Keep 55–75% paper visible on sparse plates.
  • Let the car bleed the lower edge; let the wordmark crop the sides.
  • Alternate row tones in the band list.
  • Carry halftone + paper grain over every frame.

Don't

  • Never use #FFFFFF.
  • Never re-align the misregistration layers.
  • No box-shadow, gradient fills, or gaussian blur.
  • Never repeat the same L/R split across consecutive frames.
  • Never combine red ribbon + red badge + red script on one frame.
  • Never drop a load-bearing line below 1.4cqw.
  • Never ease anything — motion is cut.
