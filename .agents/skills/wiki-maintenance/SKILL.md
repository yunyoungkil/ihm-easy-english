# 지침·위키 주기 정리 (14일 주기)

> **권장 모델**: 1~2단계(진단·안전 수리)는 **경량 모델**, 3단계(규칙 통합·삭제 초안)는 **상위 모델** (`Gemini 4 Neon` / `Claude Opus 5.5`).

## 원칙 (카파시 방식 복구 + 안전선)
- 새 규칙을 덧붙이기만 하지 않고, 주제별 살아 있는 기준 1장에 녹여 고쳐 쓴다.
- **안전한 수리(깨진 링크·목차 연결·스킬 사본 동기화)**는 묻지 않고 처리한다.
- **규칙 삭제·통폐합·실수 정원 교체**는 AI가 임의로 지우지 않고 **정리 초안을 사용자에게 먼저 보고해 확인받은 뒤** 반영한다.

## 절차

1. **자동 건강 점검 실행**
   - `npm run wiki:lint`를 실행해 아래 5가지를 숫자로 확인한다:
     1. `AGENTS.md` 줄 수(≤190줄)·바이트(≤22,000B) 및 실수 정원표 개수(≤10개, 넘으면 저장이 막힌다)
     2. 깨진 링크 수(`knowledge/` 전부 + `AGENTS.md`·`CLAUDE.md` + 프로젝트 스킬 문서)
     3. 목차(`knowledge/index.md`)·`AGENTS.md`에서 핵심 문서 링크만 따라가 닿지 않는 핵심 문서 목록(일지·인수인계에서만 이어진 문서도 빠진 것으로 본다)
     4. `.agents/skills/`·`.claude/skills/` 양쪽 폴더를 실제로 훑어 한쪽에만 있는 스킬, 필수 스킬 6종 누락, 프로젝트 스킬 길이(≤260줄), 양쪽 내용 일치
     5. `knowledge/wiki-maintenance-state.json` 기준 마지막 정리일 경과 일수
2. **안전 자동 수리 (🟢 묻지 않고 실행)**
   - 깨진 상대 경로 링크를 바로잡는다.
   - 빠진 핵심 운영·결정·지침 문서를 `knowledge/index.md`에 연결하고 갱신일을 오늘로 바꾼다.
   - `.agents/skills/`와 `.claude/skills/` 간 어긋난 스킬 파일을 맞춘다.
3. **통합·퇴역 초안 보고 (🟡 사용자 확인 후 반영)**
   - `AGENTS.md` 정원 10개 실수 중 이미 자동 검사로 옮길 수 있거나 오래 안 틀린 항목, 중복 지침 문서를 정리 초안으로 묶어 보고한다.
   - 확인받은 항목만 기존 1장에 통합하거나 `knowledge/legacy/`로 옮긴다.
4. **상태 갱신 · 검증 · 커밋**
   - `knowledge/wiki-maintenance-state.json`의 `lastCleanedAt`을 오늘 날짜(`YYYY-MM-DD`)로 갱신한다.
   - `npm run wiki:lint`와 `npm test` 통과를 확인한 뒤 바꾼 파일만 커밋·푸시한다.
