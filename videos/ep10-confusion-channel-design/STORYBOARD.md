# EP10 CONFUSION — Channel Design

## Frame 1 — 질문에서 원리까지
- **Status:** animated
- **Duration:** 12s
- **Transition:** cut
- **Type:** hook / concept reveal
- **Persuasion:** question-answer pairing, progressive disclosure
- **Beat:** curiosity → correction → aha → hold
- **Voiceover:** “컨퓨전은요? 전입니다. 모음 뒤라서요.”
- **Blueprint:** kinetic type beats, adapted for a beginner pronunciation lesson
- **Focal:** CONFUSION → 컨퓨전 → U + SI → 전

### Timing
- 0.0–3.2s: 질문과 선택지
- 3.2–4.7s: “컨퓨전은요?”
- 4.7–5.9s: “전입니다.” 정답 공개
- 5.9–7.9s: “모음 뒤라서요.” 원리 시각화
- 7.9–12.0s: 결과를 읽는 정지 구간

### Design rules
- 기존 채널 쇼츠의 검정 배경, 노란 단어 카드, 굵은 흰색 외곽선 타이포를 따른다.
- 영어 철자 강조는 `#FF0000`, 한글 음절 강조는 `#008EFF`를 사용한다.
- 노란 카드는 핵심 영어 단어에만 사용하고 설명은 카드 밖의 텍스트로 표현한다.
- 모션은 카드 안착, 선택지 등장, 정답 공개, 핵심 규칙 연결에만 사용한다.
- 안전영역은 상단과 하단만 확보한다.
- Rockabilly 비교안과 별도로 보존하는 채널 디자인 비교본이다.
