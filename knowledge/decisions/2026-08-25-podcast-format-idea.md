# 팟캐스트 형식 콘텐츠 추가 검토 (초기 브레인스토밍)

마지막 갱신: 2026-08-25

## 계기

사용자가 벤치마킹용으로 "English Leap Podcast"(Speak English With Class 채널)의 영상을 클리핑해서 공유함
(`Clippings/Don't Waste Your Life...md`). 두 진행자(Anna/Jake, Jennifer/Daniel)가 일상 주제로 대화하고,
중간에 "Crystal"이라는 어휘 전문가 코너가 핵심 표현을 정리해주는 15~30분짜리 영어 팟캐스트.
영상 제목은 한글로 되어 있어 한국 학습자를 타겟팅하지만, 콘텐츠 자체는 100% 영어 대화 —
리스닝 몰입 훈련이 목적인 A2-B1급 콘텐츠로 확인됨.

## 결론: 주제가 아니라 구조만 벤치마킹

사용자 확인: 저 채널의 **주제(일상 루틴, 시간관리 등)를 가져오자는 게 아니라, 대화체+스토리텔링+어휘 코너라는
구조를 우리 채널 정체성(발음 규칙, 왕초보 타겟)에 입혀서 벤치마킹**하자는 것.

언어 선택: 벤치마킹 채널은 청자가 이미 어느 정도 듣기가 되는 것을 전제로 영어 몰입 훈련을 시키지만,
**우리 타겟은 왕초보라 전면 영어 진행은 이탈 위험이 큼** — 진행은 한국어, 배우는 대상 단어/표현만
영어로 노출하는 기존 방식(영어 철자 빨강·한글 발음 파랑)을 유지하기로 함.

## 초안 구조 (가제: "이해하면 쉬운영어" 팟캐스트)

| 구간 | 내용 | 벤치마킹 근거 |
|---|---|---|
| 오프닝 스몰토크 | 두 목소리가 편하게 인사 (15~20초) | 레퍼런스의 "Hey Jake, how are you today" 도입 |
| 오늘의 발음 사고 | 진행자 한 명이 실제로 헷갈렸던 단어 경험담 | 레퍼런스의 개인 에피소드/스토리텔링 |
| 오늘의 규칙 | 다른 진행자(또는 "발음 선생님" 캐릭터)가 메타포로 규칙 설명 | 레퍼런스의 GPS/물병 비유 — 우리도 이미 자석·충돌 비유 사용 중 |
| 예시 단어 2~3개 | 대화 속에서 자연스럽게 등장, 발음 확인 | — |
| "오늘의 표현 정리" 코너 | 나온 단어를 다시 또박또박 정리 | 레퍼런스의 Crystal 어휘 코너 |
| 마무리 | 규칙 요약 + 댓글 유도 질문 + 관련 롱폼/쇼츠 연결 | 레퍼런스의 recap + CTA |

## 장점 / 리스크

- 장점: 새 소재 개발 부담 없이 기존 시즌 규칙 커리큘럼을 재활용 가능. 검증된 대화형 포맷의 체류시간·친근함을
  흡수(레퍼런스 채널 VPH가 91.9x, >100x 등으로 매우 높게 나타남).
- 리스크: 목소리 2개 필요(대화형 TTS 또는 실제 녹음), 대본 길이·제작 부담이 지금보다 훨씬 커짐,
  기존 "나레이터 단독" 프로덕션 라인과 완전히 다른 파이프라인이 필요함.

## 제안된 착수 방식 (아직 미확정)

시즌 롱폼/Track A·B 커리큘럼을 대체하지 않고, **채널 쇼츠 C**(시즌과 무관한 확장 슬롯, 슈와 쇼츠로
이미 실험 중이던 자리)에서 소규모로 먼저 테스트해보는 안을 제시함. 사용자가 아직 최종 결정하지 않음 —
"여기까지 대화는 킵해놓고" 요청으로 이 문서에 보존.

## 다음에 필요한 것 (착수하게 되면)

1. 진행자 캐릭터/목소리 설정 확정(이름, 톤, TTS 목소리 2개 선택)
2. 파일럿 1편 대본 작성 — 시즌1 규칙 중 하나를 소재로
3. 채널 쇼츠 C 슬롯에서 테스트 여부 및 시기 결정
4. 제작 비용(2개 목소리 TTS 등) 견적
