# 첫 시험 회의 (2026-11-14, 이 PC): chocolate 쇼츠 14초 구간

에이전트 맵(`knowledge/decisions/2026-11-14-agent-map-direction.md` 3-3절)의 **첫 시험판**이다. 이 폴더의 결과는 고정 규칙이 아니라 "이번 편의 시험 변수 근거"다. 회의 산출물이 새 규칙이 되지 않는다는 합의를 지킨다.

## 구성
- 안건: 비교 시트 `SbQVBQoRciA`(chocolate 쇼츠)의 14초(컷 4개: hook / contrast / vowel-drop / analogy)를 화면 체계·움직임·박자에서 낫게 만든 시안. 소재·대사·컷 시각은 고정. 렌더·음성 없음.
- 담당 3명(구성 작가는 대본이 고정이라 뺌, 모델 Sonnet 5.5) + 비판자 1명(Opus 5.5). 서로 보지 않고 각자 다른 레퍼런스 묶음(영어 학습 쇼츠, `knowledge/reference-measurements.md` 마지막 절)과 강제 제약 하나를 받았다.
  - 그래픽: 흰 카드 금지, 글자 덩어리 최대 2개·최소 96px
  - 모션: 컷마다 순서대로 등장·강조 3단계 이상, 연속 정지 0.8초 이하
  - 편집·사운드: 효과음 최대 4개, 컷 내부 비트 컷마다 정확히 2~3개를 나레이션 단어 시작에 맞춤
- 비판자: 항목 6개(가독·규칙 위반 수·구별성·나레이션 맞물림·정적/동적 리듬(화소 측정)·제작 위험) 0~3점, 근거는 숫자.

## 결과 (비판자 `critic/score.md`, 확신 중간)
| | 그래픽 | 모션 | 편집·사운드 |
|---|---|---|---|
| 합계(18점) | **13** | 12 | 10 |
| 96px 미만 글자 수 | 0 | 9(최소 40px) | 7(최소 44px) |
| 큰 움직임 비율 | 74% | 64% | 38% |
- 모션 시안은 배경과 알약이 기존과 같아서 정지 화면으로는 "기본에서 카드만 뺀 모습"이다. 차이는 움직임뿐이다. 편집 시안은 D 컷 나레이션이 컷 길이를 0.4~0.5초 넘는다.
- 가장 큰 결함(그래픽): D 컷이 "마음→맘"에서 끝나 "영어도 비슷해요"에 맞는 그림이 없다. 고침: "영어도"가 나오는 순간 o에 사선을 그은 chocolate를 120px 이상으로 다시 띄운다.
- 권고 조합: 그래픽의 화면 체계(모든 글자 100px 이상, 컷마다 화면 전체 배경) + 모션의 구절별 그림 순서표 + 편집의 시간 계산(초당 5.5음절, 실제 TTS 속도 5.47과 일치). 전부 별로면 그래픽으로 진행(합의).

## 이 PC에서 정한 것 (Claude, 사용자가 뒤집을 수 있음)
- 그래픽의 `choc / o / late` 세 줄 쌓기는 **의도된 음절 배치라 위반으로 세지 않는다**(규칙 ②의 취지는 우연한 줄바꿈 방지). 이 경우 그래픽 14점.
- D 컷 대사 25음절 ≈ 4.57초라 컷을 0.5초 늘릴 수 있다(실제 음성이 나오면 실측).
