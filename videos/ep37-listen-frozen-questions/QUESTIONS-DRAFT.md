# EP37 질문·대답 초안 (FACT-CHECK 전, 비교 시트 전)

> 2026-11-25 Claude Opus 5.5(DESKTOP-GPI3LM1) 초안. 장 구성·원리는 설계서 `knowledge/playbooks/2026-11-25-listen-longform-design.md` 3-3절. **소리 설명은 전부 FACT-CHECK 대상**이고, 단어 사이 T 굴림·'쥬/츄' 섞임은 "자주 그렇다"는 경향이지 늘 그런 규칙이 아니다(영상에서 단정 금지). 경쟁 영상(`xaTAV--wNxg`)의 문장 목록은 베끼지 않는다.
> 가장 큰 위험: AI 영어 음성이 실제로 이렇게 뭉개서 말해 주는지. 음성은 시트 승인 + FACT-CHECK 뒤에만 만들고, 만든 뒤 문항마다 원리대로 들리는지 확인해 안 맞으면 문항을 바꾸거나 해설을 실제 소리에 맞춘다.

| 장 | 원리(쉬운 말) | 질문 | 대답(다른 목소리) |
|---|---|---|---|
| 1 길·지하철 (외국인 관광객이 묻는다) | 힘 준 낱말만 크게, do·to·the·can 같은 작은 말은 원래 작게 지나간다. 두 단어만 잡는다 | How do I get to Seoul Station? | Take Line 1. |
| | | Which line goes to Gangnam? | The green one, Line 2. |
| | | Is this the right way to Myeongdong? | Yes, go straight. |
| | | Where can I buy a ticket? | Over there, at the machine. |
| | | Does this train go to the airport? | Yes, it does. |
| | | How long does it take to get there? | About twenty minutes. |
| 2 우리 가게 손님 | 앞 낱말 끝소리가 뒤 낱말 첫 모음에 넘어가 붙는다(Can I → 캐나이) | Can I pay by card? | Sure, go ahead. |
| | | Is it spicy? | Just a little. |
| | | Do you have this in black? | Yes, right here. |
| | | Can I take a look? | Of course. |
| | | How much is it? | It's fifteen thousand won. |
| | | Can I try it on? | The fitting room is over there. |
| 3 처음 만난 사람 (외국인 이웃·모임) | d·t 뒤에 you가 오면 '쥬'·'츄'처럼 섞인다(Did you → 디쥬, that your → 대츄어) | Did you just move in? | Yeah, last week. |
| | | Would you like some coffee? | Sure, thanks. |
| | | Could you help me with this? | No problem. |
| | | Is that your dog? | Yes, she's very friendly. |
| | | What did you say? | I said, good morning. |
| | | Where did you get that? | At the market nearby. |
| 4 여행지 (공항·호텔·가게의 일반 장면, 일화로 쓰지 않음) | 모음 사이 t가 부드럽게 굴러 'ㄹ'처럼 들린다(What are you → 와라유) | What are you looking for? | The bus stop. |
| | | Shall I put it in a bag? | Yes, please. |
| | | Are you waiting for a taxi? | Yes, I am. |
| | | What about this one? | That looks good. |
| | | Is it a little too big? | Maybe a little. |
| | | Did you get a receipt? | Yes, I've got it. |
| 5 미드·영화 속 친한 사이 (반전) | 질문 앞머리(Do you·Have you·Are you)를 통째로 빼고 끝 올림만 남긴다 | Want some? | Sure, thanks. |
| | | Got a minute? | Yeah, what's up? |
| | | Everything okay? | Yeah, I'm fine. |
| | | Ready? | Almost. |
| | | Need a hand? | No, I'm good. |
| | | Sound good? | Sounds great. |

## 사실 확인 근거 (2026-11-25 웹 검색으로 찾음, FACT-CHECK.md에 옮길 것)
- 작은 말 약해짐(the→약한 '어', to→tə, 조동사 do→də): 미시간대 ELI https://www.lrc.lsa.umich.edu/eli-538/pg-052.html · 흐로닝언대 미국 영어 발음 교재 7장 https://opentextbooks.rug.nl/americanenglishphonetics2/chapter/7-1-gradation-or-function-words/
- 끝소리 붙기: 아이오와주립대 발음 교재 10장 https://iastate.pressbooks.pub/teachingpronunciation/chapter/chapter-10-connected-speech/
- d·t+you 섞임: 흐로닝언대 교재 12.5절 https://opentextbooks.rug.nl/americanenglishphonetics2/chapter/12-5-the-palatal-approximant-j-yod-dropping/ · Kaźmierski 2016(미국 말뭉치, did you·would you 같은 흔한 말에서 잘 일어나고 낱말 사이 문법 경계가 있으면 덜 일어남) https://czasopisma.uni.lodz.pl/research/article/download/2359/1976/8493
- 모음 사이 t 굴림: 흐로닝언대 교재 9.4.1절 https://opentextbooks.rug.nl/americanenglishphonetics2/chapter/9-4-1-flapping-and-other-rules/ · https://en.wikipedia.org/wiki/Flapping (뒤 모음이 약할 때 가장 흔함, 정확한 조건은 경향)
- 질문 앞머리 생략: 영국문화원 C1 생략 https://learnenglish.britishcouncil.org/grammar/c1-grammar/ellipsis ("[Do you] Want some coffee?", "[Have you] Got…") · VOA 짧은 질문 https://learningenglish.voanews.com/a/short-form-yes-no-questions/4898081.html
- 한국 지하철 실제 확인 필요: 서울역은 1·4호선·공항철도, 강남은 2호선·신분당선(초록 2호선 대답이 맞는지 노선도로 다시 확인), 명동은 4호선.
